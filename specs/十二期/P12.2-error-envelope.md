信封给 **DSH/宿主 agent**（及 CLI `--json`），**不**给仓内 `complete()`。

## 1. 目标

1. `hybridQueryDetailed` 始终带 `degradation[]`（不依赖 `--explain`）。  
2. `query`/`find --json` 输出 `{ ok, result, degradation?, error? }`；顶层保留 `results` 兼容旧测例。  
3. 无 Key `remember`（未 `--no-extract`）**入队前** `ok: false` + `E_DISABLED`，不等 job 稍后失败。  
4. CLI 抛 `MemoryError` 且 `--json`：`{ ok: false, error }`。  
5. 仓内 LLM **不得**为错误再 `complete()`。
