# Spec P12.3 — `memory config` CLI

| 字段 | 值 |
|---|---|
| ID | P12.3 |
| 状态 | done |
| 依赖 | [`P12-config-cli.md`](P12-config-cli.md) |
| 仓库 | core `config-view` / `config-set` + CLI |

本期实现只读 + set 白名单 + doctor，**不**做 interactive wizard、**不**写密钥进 yml。

## 1. 命令

```
memory config
memory config list [--json]
memory config get <dotted.key> [--json]
memory config set <dotted.key>=<value>
memory config doctor [--json]
```

无子命令 = list。
