> 一张榜、一条管线。k=60 不动。不做 sigmoid、不做 min-max。

## 1. 目标

1. 臂内 RRF 仍 `1/(k+rank)`，融合前 **`rrf' = rrf * (k+1)`**（rank1 → 1.0）。  
2. **per-arm floor 默认开**：`rrf' < per_arm_min` 的臂贡献当 0（该 path 仍可被其他臂带进融合）。  
3. **融合后 floor 默认开**：`final_rel < fused_min` 的 hit 不进终榜。阈值偏松，只砍垃圾。  
4. embedding 非 `off` 且命中有向量时：**cosine re-score** `0.7*final_rel + 0.3*max(0, cosine)`（系数可配）。`off` 跳过。  
5. **hotness 改乘法**：`score = rel * (1 + α * hotnessBoost)`；删除 `score + 0.45 * hotness`。  
6. 真模型 rerank **默认关**；打开时失败链：model → local 启发式 → 不 rerank。  
7. `TIE_BREAK_EPS` 按 rescale 后分差重钉（默认 `0.002`），避免几乎总触发 P8.2 层并列。

## 3. 技术方案

### 3.1 管线顺序（锁定）

```
各臂召回
  → rrf' = rrf * (k+1)
  → 丢弃该臂 rrf' < per_arm_min 的贡献
  → final_rel = Σ w * rrf' + w_title*title + w_entity*entity     # 权重公式不变
  → 丢弃 final_rel < fused_min
  → 若 embedding 可用：rel = 0.7*final_rel + 0.3*max(0, cos(q, hit))
     否则 rel = final_rel
  → graph signals（现有，fail-open）
  → score = rel * (1 + α * hotness)     # hotness∈[0,1]
  → 目录预筛 / 可选 rerank / 层 tie-break
```

cosine 用 **query 向量** 与命中 **代表 chunk 向量**（已有 embedder；无向量的 hit 该项为 0，即只吃 0.7×final_rel）。

### 3.2 配置

```yaml
search:
  fusion:
    rrf_k: 60                 # 只读展示；改它视为违规
    rescale: true             # 本期恒 true
    per_arm_min: 0.70         # rrf'；约低于 ~rank 27 的臂贡献清零
    fused_min: 0.05           # 偏松
    cosine_lambda: 0.3        # rel = (1-λ)*final_rel + λ*cos；λ=0.3
  hotness:
    enabled: true
    half_life_days: 30
    alpha: 0.15               # 禁止默认 0.45；加法删除
  tokenmax:
    rerank: off               # off | local | model
    rerank_top_n: 20
```

`α=0.15` 为 **可测默认**（TODO 写「待定」= 允许夹具后续改配置，**禁止**回到加法 0.45）。验收必须包含「旧文档标题全命中 > 新文档无关」——乘法不得让时效单独赢相关度。

### 3.3 rerank

- `off`：跳过（默认，含 balanced）。  
- `local`：现启发式。  
- `model`：`complete()` 或可注入 `rerankFn`；抛错 → local → 再失败则保持融合分。  
仅 `mode=tokenmax` 且配置非 off 时跑（与现网 tokenmax.rerank 一致）；balanced 不跑 model。

### 3.4 tie-break

`TIE_BREAK_EPS = 0.002`。P8.2 测例 P82-08：分差 `<0.002` 才层偏好；`≥0.02` 相关度仍赢。更新该测例期望。
