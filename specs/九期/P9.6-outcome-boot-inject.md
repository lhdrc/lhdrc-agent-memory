## 1. 目标

1. 插件工具 `memory_skill_outcome`：`{ name, success, note?, brain? }` → 调 `applySkillOutcome`；返回 `eta_score/support/status`。  
2. **不**因 success 次数把 `candidate` 改成 `active`（现实现失败且 eta<0.4 可 archived 的行为保留）。  
3. session-start（或 agent 首次 idle 前一次）：注入该 brain **成熟经验** top-3（`eta_score` 降序，status=active 的 experience；不足则 candidate 经验不注）。失败 fail-open。  
4. 与 P8.1 门控知识注入去重：启动已注的 path，本 session 门控命中同一 path 则 skip（可选；做不到则 prompt 写「可能重复」）。锁定：**按 path 去重**，同一 session 内存 Set。  
5. section 写明：outcome 给人/模型显式打；启动经验不是 L0。

## 2. 非目标

- 自动 activate  
- 启动注入 skill 或 L0  
- Skill > 经验 > L0 系统排序  
- 前端（只保证 frontmatter 可展示）  
- 模型自报 success 的启发式（必须显式工具）

## 3. 技术方案

### 3.1 outcome

复用 `packages/core/src/write/skill.ts` `applySkillOutcome`。插件校验 brain（P8.5）。无该 skill → `E_NOT_FOUND`。

CLI 已有 `memory skill outcome`：保持；插件与 CLI 同一函数。

### 3.2 启动注入

事件：`agent/session-start` 或首条 `user/message` 前一次（与 P8.1 惰性打开并列，**每 session.id 只注一次**）。

选经验：

```
list experiences in brains/{id}/experiences/*.md
filter schema/status active
sort by eta_score desc, support desc
take 3
inject createUserMessage({ source: { kind: "plugin", plugin: "df-memory" } })
body = title + trigger/snippet，限 2k chars 总计
```

无经验 → 不注入、不报错。  
`injectOnGate` 仍按 P8.1；启动注入不受 `shouldQueryMemory` 门控。

配置（插件）：

```yaml
bootInjectExperiences: true
bootInjectTopK: 3
```
