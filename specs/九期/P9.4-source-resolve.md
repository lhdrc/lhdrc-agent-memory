## 1. 目标

统一函数 `resolveSourceIdFull(...)` 按下列顺序，**先命中先生效**，不再往下看：

1. CLI `--source` / 工具显式参数  
2. env `DF_MEMORY_SOURCE`  
3. 从 cwd（或传入 path）向上到仓根找 `.dfmemory-source`，读其中 source id  
4. **路径前缀**：目标 path 或 cwd 落在 `brains/{brain}/sources/{id}/` 下 → 该 `id`  
5. `brain.yml` `sources.default`  
6. **sole_non_default**：`sources` 映射里除 `default` 外恰好 1 个键 → 用它  
7. 字面 `'default'`

创建 brain 时写的 `.dfmemory-source` 必须被第 3 层读到。

## 2. 非目标

- 改 ACL / 多 brain  
- 自动新建 source 目录  
- 7 层都写进 git 钩子  

## 3. 技术方案

点文件格式：沿用 `sourceMarker` 现有内容；解析出 source slug，非法 → 忽略该层（fail-open 到下一层），不抛到 capture。

第 4 层：把 cwd/`--path` resolve 到仓内相对路径，匹配 `^brains/[^/]+/sources/([^/]+)/`。

第 6 层：`Object.keys(brain.sources)` 去掉 `default` 后 length===1。

CLI：`loadContext` 改为调用该函数；命令行 `--source` 仍最高。现 `o.source ?? ctx.sourceId` 保持：flag 已在第 1 层。

导出给插件：core `resolveSourceIdFull({ repoRoot, brainId, flag, cwd, path? })`。
