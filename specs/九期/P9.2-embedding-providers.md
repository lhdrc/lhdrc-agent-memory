> 三档可配：云 API、本地真模型、不联网哈希。默认 API。无 Key / 出网失败 **fail-open 哈希**，query 不炸。CI 禁止依赖网络。

## 1. 目标

1. `embedding.provider` 取值：`openai` \| `onnx` \| `local` \| `off`（`off` 已有，杀语义臂）。  
2. **`init` 默认 `openai`**。  
3. `local` **保持**确定性 bigram 哈希（现 `embed/local.ts`；类名若叫 Onnx 则改名，避免误导）。  
4. 新增 `onnx`：钉死权重的离线真模型（无网络）。本期若权重打包过大：接口 + 加载失败码先齐，可用「未安装权重 → `E_DISABLED` + 降级哈希」；**禁止**用哈希冒充 `onnx` 成功。  
5. 无 `OPENAI_API_KEY`（或配置的 env）时：不抛到 CLI 顶层；语义臂改用 `local` 并 `--explain` / log 记 `embedding_fallback: local`。  
6. provider/dims/model 变化仍走 `embeddingMetaMismatch` → 提示 `rebuild-index --embeddings`。

## 2. 非目标

- 真 pgvector / HNSW（下期 #9）  
- 把 `local` 升级成真模型  
- 默认联网测例  
- npm 分发模型文件的强制体积承诺（onnx 权重路径可配）

## 3. 技术方案

### 3.1 配置

```yaml
embedding:
  provider: openai          # init 默认；测例仓写 local
  model: text-embedding-3-small
  dims: 1536                # openai 默认；local 哈希 384
  openai_api_key_env: OPENAI_API_KEY
  onnx_model_path: ""       # provider=onnx 时必填或内置相对路径
```

`createEmbeddingProvider`：

| provider | 实现 |
|---|---|
| `openai` | 现 `OpenAIEmbedding`；缺 key **不** throw 到 factory，由 `createEmbeddingProviderForQuery` 降级 |
| `onnx` | 新 `OnnxEmbedding`；文件缺失 → 降级 `local` + 可观测 |
| `local` | 现哈希 |
| `off` | `NoopEmbedding` |

降级只发生在 **query/embed 热路径**。`rebuild-index --embeddings` 在 openai 缺 key 时 → `E_DISABLED`（不要默默写成哈希向量污染索引）。锁定：

- **读路径**（hybrid 语义臂）：fail-open 哈希或关臂  
- **写路径**（sync 嵌入）：缺 key 且 provider=openai → 跳过嵌入（chunk 无向量）或 `E_DISABLED` 由 CLI 决定；**禁止**把哈希向量写入「meta 声称 openai」的索引  

推荐：写路径缺 key 时 `embedding-meta` 记实际 `local`，与读路径一致，避免 meta 撒谎。首次成功用 API 后 meta 为 openai，之后缺 key 读路径降级哈希但 **拒绝混用旧 openai 向量**（已有 mismatch 检测）→ 语义臂关或要求 rebuild。

更简单的可测锁定（本期采用）：

```
resolveEmbedder(cfg):
  if provider==off: noop
  if provider==local: hash
  if provider==onnx: load or fallback hash + flag
  if provider==openai:
    if hasKey: openai
    else: hash + flag fallback=true
```

写与读同一 resolve。meta 记录 **实际** provider。从 openai 向量切到哈希会 mismatch → 语义臂 skip 直到 rebuild（fail-open 关语义，BM25+图仍可用）。

`memory init` 写出默认 openai。  
`rebuild-index --embeddings`：缺 key → `E_DISABLED` 且非 0 退出（写路径严格）。  
query 缺 key：退出 0，hits 仍有，explain 含 fallback。
