## 1. 目标

1. 经验成熟 → `brains/{id}/skills/{name}/SKILL.md`  
2. 状态机 candidate → active → archived；反例收集  
3. dream cycle：**先 5 段精简**，再扩到 9 段  
4. observer + cost 基础记账  
5. CLI：`skill` / `dream` / `observer`  
6. **索引 skills**（P2.2 仍可跳过；本 Spec 起 active skill 可被 query）  

## 2. 非目标

- 无确认的自动硬删  
- 无确认的自动 entity merge（dream 只建议）  
- MCP / REST（P4.1）；outcome 回调以 CLI 为准，工具面后挂  

## 3. 成熟判定

```
eta_score >= 0.7 && support >= 2 && counter_examples.length == 0
```

字段存 experience frontmatter（P2.2 已预留默认值）：

- `eta_score`：初始 0.5；每次注入后成功回调 +0.1，失败 -0.2（经 `skill outcome` / `experience outcome` CLI）  
- `support`：成功复用次数  

公式可配置，但默认必须写死在代码常量并单测。

## 4. SKILL.md 格式

见 08 §9.2。目录：

```
brains/{id}/skills/{name}/
  SKILL.md
  (optional) scripts/
```

`name`：`[a-z0-9-]{1,64}`。写入经 `validateWrite`（D14）；扩展 WRITE_FORMAT 覆盖 skill。

结晶步骤：

1. 选同 trigger 经验簇  
2. LLM `refineExperience` 归纳 procedure/boundary/verification  
3. 写 SKILL.md status=candidate  
4. memory_diff  
5. 人工或 `memory skill activate <name>` → active  

反例：`memory skill outcome <name> --fail --note "..."` → 写入 counter_examples；可降为 archived。

## 5. Dream 精简 5 段（v1 必须）

| # | 阶段 | 行为 |
|---|---|---|
| 1 | lint | frontmatter/路径/pack 校验；只报告或 `--fix` 修可自动项 |
| 2 | sync | 调用索引增量同步 |
| 3 | distill_pending | 对未蒸馏源跑 refine（受 kill_switch） |
| 4 | contradictions | 同 path 冲突 facts 启发式标记 → contradictions.md（不删 facts）。**跨文件 cosine 见 P10.3（B）** |
| 5 | orphans | 显式临时 note（`temporary`/`ephemeral` 或 tag）且无引用 → status=archived |

v2 再补：backlinks、synthesize、extract、patterns、recompute_weight、embed --stale（对齐 08 九段）。

CLI：`memory dream [--fix] [--phases 1,2,3]`

约束：dream **不得**物理删 sources；不得无确认 merge entity。

## 6. Cost / observer

```yaml
# memory.yml
cost:
  daily_token_cap: 0        # 0 = 不限制
  log: .dfmemory/costs.jsonl
```

每 LLM 调用 append：`{at, kind, tokens_in, tokens_out, model}`。  
超 cap → 该类调用跳过并记降级。

`memory observer`：打印 query 次数、zero-result 率、avg score、distill 次数、cost 汇总（从日志聚合）。
