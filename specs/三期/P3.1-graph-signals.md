## 1. 目标

1. 写入/同步时从正文提取 typed links（零 LLM）  
2. 索引表 `links`  
3. 关系查询臂 + CLI `graph-query`  
4. graph signals 调权（fail-open）  
5. 意图分类（正则）接入 query  
6. `search_cache`（knobs_hash）  
7. 在 P2.1a 冻结公式上 **扩展** graph / entity 臂权重（对齐 08 §7.2 完整形态）  

## 2. 非目标

- LLM NER  
- 分布式图数据库  
- MCP / REST（P4.1）  

## 3. DDL 增量

```sql
CREATE TABLE IF NOT EXISTS links (
  id TEXT PRIMARY KEY,              -- hash(from,to,type,source)
  from_path TEXT NOT NULL,
  to_ref TEXT NOT NULL,             -- path 或 entity slug
  type TEXT NOT NULL,
  source TEXT NOT NULL,             -- wikilink|markdown|mention|verb|path|frontmatter
  brain_id TEXT NOT NULL
);
CREATE INDEX IF NOT EXISTS links_from ON links(from_path);
CREATE INDEX IF NOT EXISTS links_to ON links(to_ref);

CREATE TABLE IF NOT EXISTS search_cache (
  cache_key TEXT PRIMARY KEY,       -- hash(query + knobs_hash)
  knobs_hash TEXT NOT NULL,
  response_json TEXT NOT NULL,
  created_at TEXT NOT NULL
);
```

## 4. 抽链算法 `extractEntityRefs`

对 body（先 `stripCodeBlocks`）：

| Pass | 模式 | type 默认 |
|---|---|---|
| 1 | markdown `[text](path)` | references |
| 2 | qualified wikilink `[[source/path]]` | references |
| 3 | wikilink `[[title]]` | mentions |
| 4 | `@slug` mention | mentions |

`inferLinkType` 正则（正文动词窗口，可配置）：

- `决定|decided` → decided  
- `产出|produced` → produced_by  
- `负责|works on` → works_on  
- `属于` → belongs_to  

合并 frontmatter `links`；同 (from,to,type) 去重。masked-ranges 防双发。

同步时：删该 from_path 旧 links，再插入新 links。

## 5. 关系臂

```
parseRelationalQuery(q):
  匹配「X 的 Y」「谁负责 X」「X references」等确定性模板
  → { seed, verb } | null
if null → 空臂 fail-open
else BFS links depth≤2 from seed → hydrate pages
```

## 6. graph signals（对 top-K 重权）

| 信号 | 乘子 | 条件 |
|---|---|---|
| adjacency hub | 1.05 | ≥2 个 top-K 互相有边 |
| cross-source | 1.10 | ≥2 不同 source 链入 |
| session diversify | 0.95 | 同 source 多条只保留最高 |

任一异常 → 跳过该信号。

## 7. 意图分类与融合扩展

零 LLM：schema pack `intent_lexicon` + 内置。

`task|experience|person|general` → 调 RRF 权重（person 抬 entity boost；experience 抬 experiences 路径）。

含 graph 臂时的融合（本 Spec 冻结；无 `graphHits` 时仍走 P2.1a 无图公式）：

```
final = w_kw * rrf(bm25) + w_sem * rrf(semantic) + w_graph * rrf(graph)
      + w_title * title_path_boost_norm + w_entity * entity_boost_norm
```

**hotness** 不在上式内：由 `hybrid.ts` 在融合与 graph signals 之后作 post-fusion 乘子（对齐 08 §7.2 的 0.15 槽位）。

冻结权重（`packages/core/src/retrieve/rrf.ts`，各项之和 = 1）：

| 场景 | w_kw | w_sem | w_graph | w_title | w_entity |
|---|---:|---:|---:|---:|---:|
| balanced / general / task（语义开） | 0.35 | 0.20 | 0.20 | 0.10 | 0.15 |
| 无语义 general/task（08 降级） | 0.55 | 0 | 0.30 | 0.10 | 0.05 |
| relation（语义开） | 0.20 | 0.15 | 0.45 | 0.10 | 0.10 |
| relation（无语义） | 0.30 | 0 | 0.55 | 0.10 | 0.05 |
| person | 0.25 | 0.15 | 0.15 | 0.10 | 0.35 |
| experience | 0.30 | 0.25 | 0.15 | 0.15 | 0.15 |

语义不可用时 `w_sem` 项为 0，直接选用上表「无语义」行（不做 w_sem 再分配）。`/experiences/` 路径 entity boost 仍在 `fuseHybridArms` 侧叠加。

## 8. CLI
