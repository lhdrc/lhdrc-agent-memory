# Spec P10.5 — HaluMem 官方评测协议（halumem-official-v1）

| 字段 | 值 |
|---|---|
| ID | P10.5 |
| 状态 | in_progress |
| 依赖 | P6.3 `compileSession`、P7.1 `complete()`、P9.2 embedding 三档 |
| 来源 | [HaluMem arXiv:2511.03506](https://arxiv.org/abs/2511.03506) Appendix C；[MemTensor/HaluMem](https://github.com/MemTensor/HaluMem) `eval/` |
| 仓库 | 本仓 `evals/`；**不改** DSH 插件 |

> **与 P10.1 关系**：LoCoMo 发数仍走 `locomo-prompts.ts`（J-score）。HaluMem **禁止**复用 LoCoMo 答题/judge 当官方数字。  
> **与 halumem-v1 关系**：`halumem-v1` 保留为内部趋势（LoCoMo J-score + 规则 extract）；**默认** `--adapter halumem` 走 **`halumem-official-v1`**。

## 1. 目标

1. 锁定 HaluMem 论文 **Appendix C.1/C.2** prompt 全文 + SHA256（见 `evals/adapters/halumem-prompts.ts`）。
2. QA：**top_k=20**；Update 验证检索：**top_k=10**。
3. Extract / Update / QA 分项用 **LLM JSON judge**（integrity score 0/1/2；update Correct/Hallucination/Omission/Other；QA Correct/Hallucination/Omission）。
4. receipt 标 `protocol: halumem-official-v1`；**禁止**与 Mem0/HaluMem 榜无声明对比。

## 2. 非目标

- 替换 LoCoMo P10.1 J-score
- 全量 HaluMem-Medium 进 CI（太贵；CI 用 `--fixture` + mock）
- 改 `session-extract-v1.md` 专伺 HaluMem

## 3. 合同（已锁定）

| 项 | 锁定 |
|---|---|
| 协议 id | `halumem-official-v1` |
| 数据 | `HaluMem-Medium.jsonl`（现有 fetch pin） |
| 写入 | 每 session `compileSession`（默认）；`--ingest capture` 仅调试 |
| QA 检索 | `hybridQuery` top_k=**20**（`--top-k` 可覆盖，receipt 必记） |
| Update 检索 | top_k=**10** |
| 答题 prompt | C.1 结构 + df-memory context（`halumem-prompts.ts` `HALUMEM_ANSWER_TEMPLATE`） |
| Judge prompt | C.2  verbatim：`HALUMEM_INTEGRITY_JUDGE` / `HALUMEM_UPDATE_JUDGE` / `HALUMEM_QA_JUDGE` |
| QA judge 输入 | question + gold + **`qa.evidence` key memory points** + predicted |
| Integrity 命中 | LLM `score == 2` |
| Update 命中 | LLM `evaluation_result == Correct` |
| QA 主指标 | `correct_ratio`（Correct / n）；分项 hallucination / omission |
| 模型 pin（论文） | GPT-4o；实现允许 `DF_EVAL_CHAT_MODEL` / `DF_EVAL_HALUMEM_JUDGE_MODEL` 覆盖，receipt 分开记 |
| 内部趋势 | `--protocol halumem-v1` → LoCoMo J-score + 规则 extract |

## 4. 模块落点

| 路径 | 用途 |
|---|---|
| `evals/adapters/halumem-prompts.ts` | C.1/C.2 锁仓 + hash |
| `evals/adapters/halumem-official-eval.ts` | JSON 解析、context 格式化、L0 读取 |
| `evals/halumem-run.ts` | publish runner（protocol 分支） |
