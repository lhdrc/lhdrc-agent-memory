> 结构不动（四 pass + `links` 表 + 图臂 + signals）。本期只加 **规则密度** 和 **查询防御**。

## 1. 目标

1. 默认动词从 4 条扩到冻结词表（中英），类型必须 ∈ `KNOWN_LINK_TYPES`。  
2. schema pack 可加 `extra_verbs`（pattern + type）；非法 type / 危险正则 **丢弃该条**，不影响默认词表。  
3. 邻接臂种子：**停用词、过短、无边界的子串** 不得当种子。  
4. 关系查询解析：种子长度上限、停用词拒绝；模板保持锚定，避免 ReDoS。  
5. 仓内夹具：至少 2 条「谁在哪 / 谁负责」类 query，图臂非空。

## 2. 非目标

- `link_kind` 列或细分 source  
- 按 page schema_type 绑默认边（media→mentions 等）  
- 批量 `jsonb_to_recordset` 写入  
- 新 schema pack / 换默认 pack  
- LLM NER  
- postgres HNSW（#9）  
- 改 RRF 权重表（P3.1 / P9.3 冻结）  
- 把 graph signals 的 diversify 从 source 改成主题（另案，不进本期）

## 3. 技术方案

### 3.1 已知边类型（冻结）

实现里导出常量 `KNOWN_LINK_TYPES`（小写）。默认 + pack 只能产生下列 type：

```
mentions, references, decided, produced_by, works_on, belongs_to,
works_at, founded, invested_in, advises
```

不在集合内的 pack `type` → 该 `extra_verbs` 行丢弃。

### 3.2 默认动词（core，零 LLM）

在 `link-extraction.ts` 的默认表上 **追加**（保留原 4 条）：

| pattern（示意） | type |
|---|---|
| `任职` / `就职` / `工作于` / `works at` / `works_at` | `works_at` |
| `创立` / `创办` / `founded` | `founded` |
| `投资` / `invested in` | `invested_in` |
| `顾问` / `advises` | `advises` |

窗口推断仍用现网 `inferLinkType`（匹配点前后 40 字）。测例：正文 `Alice 任职于 Rivermark` 且有 `@rivermark` 或 `[[Rivermark]]` → 边 type `works_at`。

### 3.3 pack `extra_verbs`

`problem-tree.yml` 与 `loadPack` 增加可选：

```yaml
extra_verbs:
  - pattern: "带队|led"
    type: works_on
```

规则：

- `pattern` 字符串最长 64；禁止 `(?=`, 禁止嵌套量词 `{n,}` 且 n>32；编译失败则丢弃该行。  
- 与默认表 **合并**：先默认后 extra；同一窗口先命中先生效（与现网 for-循环一致）。  
- 抽链调用方（sync / compile linkify）必须传入 pack 动词；pack 读失败 → 仅默认表（fail-open）。

### 3.4 邻接种子门控

现网 `collectAdjacencySeeds`：实体名 / `to_ref` 只要是 query 子串（长≥2）即种子。

改为同时满足：

1. 针长：ASCII 纯字母数字 ≥3，或含 CJK ≥2。  
2. 针不在停用词表（大小写不敏感）。内置至少：`the, a, an, of, and, or, is, 的, 了, 和, 与, 谁, 什么, 如何`。  
3. ASCII：按词边界命中（`\b`）；CJK：允许子串。  
4. 种子最多 **8** 个（先实体 registry 再 links `to_ref`，超出截断，稳定排序：slug 字典序）。

无种子 → 图臂空，fail-open（P3.1 不变）。

### 3.5 关系查询防御

`parseRelationalQuery`：

- 保持 `^…$` 锚定模板；可 **追加** 英文 `who works at X` / `who founded X`（seed 长度 1–64）。  
- 解析出的 seed 若在停用词表或仅标点 → 当解析失败（返回 null）。  
- 现网 `seed.length > 128` 改为 **> 64** 拒绝。

不对用户输入 `new RegExp(query)`。

### 3.6 夹具

`packages/core/tests/fixtures/graph-relation.md`（或现有 m3 风格临时仓）：

- 两实体 + 正文含任职/负责。  
- `graph-query` 或 `hybridQuery` 在 relation/person 问句下，图臂 `explain.arms.graph` 至少 1 条。
