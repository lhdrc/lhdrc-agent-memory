## 1. 目标

1. dream 第 4 段在现有「同文件 facts 重叠」之外，增加 **跨文件** 近似 facts 对。  
2. 相似度用仓内 embedder 的 **cosine**（与 P5.1 去重同一套向量空间）。  
3. 只追加写 `brains/{brainId}/contradictions.md`；**不删、不改** L0 facts，不改 `hybridQuery` 分数。  
4. embedding 为 `local` 哈希时：**跳过跨文件 cosine**（误报高），只跑同文件启发式。  
5. 失败 fail-open：嵌入抛错 → 本轮无跨文件行，同文件段仍写。

## 2. 非目标

## 3. 技术方案

### 3.1 扫描范围

与现网 phase 4 相同：`brains/{id}/sources/**/*.md`（不扫 experiences/skills，除非已有测例要求——**本期不扫**）。

每条参与跨文件比较的单元：

- `facts[].text` 去首尾空白；空串跳过。  
- 无 facts 的文件 **不**用正文冒充（避免整篇 note 两两爆炸）。

### 3.2 跨文件配对

```
候选 = 所有 (path, factIndex, text)
仅当 embedding.provider ∈ {openai, onnx} 且 embedder 可用：
  向量 = embedder.embed(texts)
  若 i.path ≠ j.path 且 cosine(i,j) ≥ 0.95
    → 记一行候选 DUPLICATE
同文件对仍走现网启发式（文本包含 / 前 40 字相同 且 event_type 不同）
```

- 上限：单 brain 最多比较 **500** 条 facts（超出按 path 字典序截断，receipt/details 记 `truncated: true`）。  
- 最多写入 **100** 条跨文件发现（防止 contradictions.md 爆炸）。  
- `onnx` 无权重 / `openai` 无 Key → 视为不可用，跳过跨文件（与 P9.2 fail-open 一致）。

### 3.3 文件格式

`brains/{brainId}/contradictions.md` 仍每次 dream **整文件覆盖**（与现网一致）。结构：

```markdown
# Contradictions

> dream @ <ISO>

## intra-file

- path: facts[i] vs facts[j] …

## cross-file

- duplicate cosine=0.96 `brains/.../a.md` facts[0] ↔ `brains/.../b.md` facts[1]
  - a: "…"
  - b: "…"

_no contradictions detected_   # 两节都空时保留现网这句，可同时无 ## 节
```

跨文件行必须含两个 path 与 cosine（四位小数）。不写向量。

### 3.4 与检索的关系

**无（本期）。** `hybridQuery` / query log / observer 不读 contradictions.md。产品要「过期事实降权」见十一期 **[`P11.4`](../十一期/P11.4-stale-demote.md)**。
