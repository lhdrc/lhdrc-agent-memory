# Spec P5.2 — 分层读写（L0/L1/L2）

| 字段 | 值 |
|---|---|
| ID | P5.2 |
| 状态 | done |
| 依赖 | M2；建议 P2.2 |
| 对应架构 | 08 §6.5、§7.1「分层加载」 |

## 1. 目标

1. 可生成节点 **L0 `abstract`** 与 **L1 `overview`**（启发式必可用；LLM 可选增强）  
2. 存储：frontmatter `abstract` / `overview`；超长 overview 可 sidecar  
3. **目录级**聚合：`layers refresh --dirs` 写出目录摘要文件（可用）  
4. **`memory read --layer l0|l1|l2`** 按层返回；默认 l2 兼容旧行为  
5. **`memory layers refresh`** 对指定 path/全 brain 可重算  
6. `layers.auto: true` 时 capture 后自动写至少 L0（不依赖云）  

## 2. 非目标

- 用分层替换 `## 正文`  
- dream 扩段  
- MCP 传输（P4.1 复用 read API）  

## 3. 技术方案

### 3.1 层定义

| 层 | 内容 | CLI |
|---|---|---|
| L0 | `abstract` | `read --layer l0` |
| L1 | `overview` | `read --layer l1` |
| L2 | 全文 | `read` / `--layer l2` |

### 3.2 配置与命令

```yaml
layers:
  auto: false
  overview_max_chars: 4000
  dir_aggregate: true
```

```
memory layers refresh [--path <rel>] [--dirs] [--json]
memory read <path> [--layer l0|l1|l2] [--json]
memory capture …   # layers.auto=true 时写 abstract
```

`--json` read：`{ path, layer, content, chars }`。  
`layers refresh --json`：`{ updated: [{path, abstract:true, overview:true}] }`。

目录摘要落盘约定（须文档化且实现一致）：`brains/{id}/…/{dir}/_overview.md` 或目录节点 frontmatter；验收以 `read`/`cat` 能看到聚合子标题为准。

### 3.3 检索衔接

`query` hit 增加可选 `abstract` 字段；`snippet` 优先 abstract（本 Spec 验收 P52-06）。

## 4. 验收（须可跑）

| ID | 功能点 | Given / When / Then（口令） |
|---|---|---|
| P52-01 | 启发式 refresh | `llm=off`；capture 长文 → `layers refresh --path <rel> --json` → 该文件 frontmatter 非空 `abstract` 与 `overview` |
| P52-02 | 按层读 L0 | `read <path> --layer l0 --json` → `chars` 明显小于 l2；content 不含完整长正文 |
| P52-03 | 按层读 L1 | `read --layer l1` 长度介于 l0 与 l2（或等于 overview） |
| P52-04 | 目录聚合 | 同目录 ≥2 节点 → `layers refresh --dirs --json` → 目录摘要存在且含子节点 title |
| P52-05 | auto 开关 | `layers.auto=true` → 一次 `capture` 后无需 refresh 即有 `abstract`；`auto=false` 则无（除非 refresh） |
| P52-06 | query 用摘要 | refresh 后 `query` 命中该 path → JSON/`snippet` 侧可见 abstract 优先（人工或 `--json` 断言） |
| P52-07 | 兼容默认读 | 无 `--layer` 的 `read` 仍输出全文（l2），与现网一致 |
