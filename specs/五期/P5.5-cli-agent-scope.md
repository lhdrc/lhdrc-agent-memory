## 1. 目标（每项须 CLI 可验证）

1. **`memory find`**：与 `query` 同库同 mode 结果一致，flags 透传  
2. **`memory think`**：有数据时返回 skills/experiences/notes 结构化结果；空库冷启动提示  
3. **`memory eval --mini`**：可跑通迷你评测并透传退出码  
4. **`memory agent register|list`**：注册表落盘可查  
5. **`--agent` 范围**：agent 只能写/读登记 source；越权失败；trusted local 无 agent 不变  

## 2. 非目标

- MCP 传输细节（P4.1 复用 authorize）  
- 完整 RBAC UI  

## 3. 技术方案

```
memory find <text> [--limit] [--mode] [--json] …
memory think <text> [--json]
memory eval [--mini] [--json]
memory agent register --id <id> --source <s> [--source <s2>]
memory agent list [--json]
memory --agent <id> [--token <t>] capture|query|read|…
```

`think --json` 形状：

```json
{
  "query": "…",
  "skills": [],
  "experiences": [],
  "notes": [],
  "hints": ["cold_start" | "…"]
}
```

Agent 文件：`brains/{brainId}/agents/{id}.yml`。

## 4. 验收（须可跑）

| ID | 功能点 | Given / When / Then（口令） |
|---|---|---|
| P55-01 | find 可用 | 写入笔记后 `find "关键词" --json` 与 `query "关键词" --json` 的 path 集合相等 |
| P55-02 | find flags | `find "x" --mode conservative --limit 3` 退出 0（与 query 相同 flag） |
| P55-03 | think 空库 | 新仓 `think "任意" --json` → hints 含冷启动类提示；退出 0 |
| P55-04 | think 有数据 | 预置 experience 或 skill + note → `think "相关词" --json` → 至少一个数组非空 |
| P55-05 | eval 可用 | `memory eval --mini` 退出码与 `bun run eval:mini` 一致且 stdout 有摘要 |
| P55-06 | agent 注册/列表 | `agent register --id bot --source default` → `agent list --json` 含 bot 与 sources |
| P55-07 | agent 授权写 | 登记仅 `default`；`--agent bot --token <member>` capture 到 default **成功** |
| P55-08 | agent 越权 | 同 bot 写 `other-source`（已存在于 brain 但未登记）→ `E_FORBIDDEN`；无新文件 |
| P55-09 | 无 agent 兼容 | 不带 `--agent` 的本地 CLI capture/query 与现网一致 |
| P55-10 | HELP | `memory help` / 无参 列出 find、think、eval、agent |
