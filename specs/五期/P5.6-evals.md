## 1. 目标（每项须可跑，禁止空 stub 算完成）

1. **`eval:mini` / `memory eval --mini`**：无网跑通，写出 **receipt 文件**  
2. **检索回归门禁**：夹具查询；破坏索引后必须失败  
3. **蒸馏有效性 mini-bench**：有经验 vs 无经验两场景，输出可比较指标（规则代理即可）  
4. **`eval:report`**：读取最近 receipt 打印摘要  
5. **公开适配器**：至少 **一个** 适配器在 **fixture 子集**（仓库内小型样例，非全量下载）上可跑；全量 LoCoMo/LongMemEval 通过 `eval fetch --allow-net`（可选）  
6. 未准备数据时错误信息可操作（告诉用户 fetch 或用 fixture）  

## 2. 非目标

- 托管排行榜  
- 强制贡献者下载超大语料  
- 替换 bun:test 单元测试  

## 3. 技术方案

```
bun run eval:mini
bun run eval:distill
bun run eval:report
memory eval --mini|--distill|--adapter <id> [--fixture] [--json]
memory eval fetch --adapter <id> --allow-net   # 可选
```

仓库内必须有：

```
evals/fixtures/mini/          # 检索
evals/fixtures/distill/       # 有/无经验
evals/fixtures/locomo-sample/ # 或等价 ≤ 几条 case 的公开格式子集
evals/adapters/types.ts
evals/receipts/.gitkeep       # 运行产物 gitignore
```

**禁止**：adapter 目录只有 README、`run` 直接 `E_DISABLED` 却声称 P5.6 done。

## 4. 验收（须可跑）

| ID | 功能点 | Given / When / Then（口令） |
