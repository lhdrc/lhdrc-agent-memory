# Spec P5.1 — L0 提取与写入快路径

| 字段 | 值 |
|---|---|
| ID | P5.1 |
| 状态 | done |
| 依赖 | M2；建议 P2.1a（embedding 用于 cosine 快路径） |
| 对应架构 | 08 §6.3、D11、D12、D17 L0 |

## 1. 目标

1. L0 写入后可选 **余弦快路径**：与近期 facts/正文 embedding 相似度 ≥ 阈值 → **跳过重复写入语义**（记 skip 审计，不删已有文件）  
2. 可选 **提取** `facts` / entity mentions：`llm.extract` 或 CLI `--extract`；默认 **off**  
3. **`provider=off` 时仍可用**：内置 **启发式提取**（从正文列表项/`##` 小节抽 fact 文本），保证无 API Key 可演示  
4. 提取结果经 WRITE_FORMAT 校验后 **append** 到 frontmatter `facts`（ADD-only）；**禁止**覆盖正文、禁止改他人 source  
5. kill-switch：`llm.kill_switch.extract`；超 cost cap → 跳过提取并记 cost log  
6. CLI：`capture --extract` / `--no-dedupe`；`import` 同样尊重配置  

## 2. 非目标

- 改/删 `sources/` 既有正文（D17）  
- 完整 OpenViking 两级蒸馏（已有 P2.2 `refine`）  
- MCP/REST（P4.1）  
- dream / 夜间维护扩段  

## 3. 技术方案

### 3.1 配置

```yaml
# memory.yml
llm:
  provider: off | openai
  extract: false
  kill_switch:
    distill: false
    abstract: false
    extract: false
embedding:
  provider: local | openai | off
write:
  dedupe_cosine: 0.95     # ≤0 关闭；embedding off 时忽略并在 --json 提示 skipped_reason
  dedupe_window: 200
```

### 3.2 管线

```
validateWrite → 写队列落盘 md
  → onAfterWriteEnrich(path)（--extract 或 extract=true 或 dedupe>0 时）:
       1. dedupe：embedding on 且相似度≥阈值 → memory_diff op=skip_duplicate；enrich 结束
          （注：节点已按 ADD-only 落盘；「跳过」指跳过提取/重复语义标记，不删文件）
       2. extract：HeuristicExtract | LLM.extractFacts
            → 校验 → patch facts append → 索引 hook
       失败：stderr warn + cost；不回滚 md（D1）
```

`capture --json` 输出须含：`{ path, enrich?: { deduped?, extracted_facts?, skipped_reason? } }`。

### 3.3 模块落点

| 模块 | 路径 |
|---|---|
| 快路径 | `packages/core/src/write/dedupe.ts` |
| 启发式/LLM 提取 | `packages/core/src/write/extract.ts` |
| prompt | `packages/core/resources/extract-v1.md` |
| hook | capture/import 后 `EnrichHooks` |

## 4. CLI

```
memory capture --title T --type note --body "…" [--extract] [--no-dedupe] [--json]
memory import <file>   # 读 memory.yml 的 extract/dedupe
```

环境：`DF_MEMORY_EXTRACT=1`。

## 5. 验收（须可跑）

| ID | 功能点 | Given / When / Then（口令） |
|---|---|---|
| P51-01 | 默认关闭 | 默认 yml → `capture` 无 enrich 字段；与改前行为一致 |
| P51-02 | 余弦去重可用 | `embedding.provider=local`，`dedupe_cosine=0.95`；连续两次近似正文 `capture --json` → 第二次 `enrich.deduped=true` 且 `memory changes`/`memory_diff` 可见 skip |
| P51-03 | 启发式提取可用 | `llm.provider=off` + `capture --extract --json`，body 含 `- 事实A` → 文件 frontmatter `facts` 含「事实A」；stdout `extracted_facts>=1` |
| P51-04 | 校验失败可感知 | mock/夹具注入非法 fact → stderr/`--json` 含 `E_VALIDATION`；**正文文件仍在** |
| P51-05 | kill-switch | `kill_switch.extract=true` + `--extract` → 跳过；`--json` 含 `skipped_reason=kill_switch` |
| P51-06 | import 同源 | `import` 夹具文件在 `extract: true` 时同样写入 facts（或明确文档：import 仅在配置开启时 enrich） |
| P51-07 | `--no-dedupe` | 同 P51-02 条件加 `--no-dedupe` → 不出现 `deduped=true` |
