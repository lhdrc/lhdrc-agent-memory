## 1. 目标（每项须可跑；禁止「仅 README 草稿」算完成）

1. **`memory ingest --adapter generic-jsonl --input <file>`** 批量写入  
2. **非法行** 结构化错误；`--continue-on-error` 可跳过坏行继续  
3. **写入只经 validateWrite + 写队列**（测试 spy / 无直写）  
4. **`df-app` 适配器可对仓内 fixture 跑通**（模拟导出 JSON/JSONL，不依赖真实 df-app 进程）；映射表进 README  
5. **`memory ingest --list-adapters`** 列出已注册适配器  

## 2. 非目标

- df-app 硬编码进 core  
- 长驻 webhook（可后置；本 Spec 批处理 CLI）  
- MCP/REST  

## 3. 技术方案

```
memory ingest --list-adapters
memory ingest --adapter generic-jsonl --input ./fixtures/notes.jsonl [--json] [--continue-on-error]
memory ingest --adapter df-app --input ./packages/adapters/ingest-df-app/fixtures/sample-export.jsonl [--json]
```

`df-app` 适配器：`map()` **必须实现**对 fixture schema 的转换（session→source、message→body）；不是 `throw E_DISABLED`。与真 df-app 版本差异在 README 标明。

workspaces：`packages/adapters/*`。

## 4. 验收（须可跑）

| ID | 功能点 | Given / When / Then（口令） |
|---|---|---|
| P58-01 | list-adapters | `ingest --list-adapters` 含 `generic-jsonl` 与 `df-app` |
| P58-02 | generic 写入 | 两行合法 jsonl → `ingest … --json` → 两 path；`query` 能命中标题词 |
| P58-03 | 非法行 | 一行缺 title → 非 0 或 `--json` errors[]；默认不写坏行 |
| P58-04 | continue-on-error | 一好一坏 → flag 开启后好行落盘、坏行进 errors；退出码文档约定（如 2） |
| P58-05 | 不绕过队列 | 单测：ingest 路径调用 `captureNode`/`WriteQueue.execute`，不直接 `writeFile` 到 sources |
| P58-06 | df-app fixture | `ingest --adapter df-app --input <sample>` → ≥1 文件落在 `brains/…/sources/…`；`read` 成功 |
| P58-07 | HELP | `ingest --help` 说明 adapter、input、continue-on-error |
