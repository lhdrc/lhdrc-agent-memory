# Spec P5.3 — 检索增强（tokenmax / 实体层 / hotness）

| 字段 | 值 |
|---|---|
| ID | P5.3 |
| 状态 | done |
| 依赖 | P2.1a、P3.1；建议 P5.2 |
| 对应架构 | 08 §7.1–7.2、§7.5、§14 |

## 1. 目标（每项须 CLI 可验证）

1. **`query --mode tokenmax`**：multi-query 扩写（LLM 可用时）；**`llm=off` 时用启发式扩写**（分词/同义模板 ≥1 变体）保证可演示  
2. **rerank**：`search.tokenmax.rerank=local` 启用本地/启发式 rerank；`off` 可关；失败 fail-open  
3. **entity boost**：query 命中 entity registry → 关联文档分升；`--explain` 可见  
4. **alias hop**：按别名查询能召回规范名文档  
5. **title-phrase boost**：标题连续短语命中可观测（explain 或对照分）  
6. **hotness**：近写入文档相对更靠前；可 `hotness.enabled=false` 关闭对照  
7. **directory_prefilter**：配置打开后，`--explain` 含预筛目录；能影响召回集合或扩窗  

## 2. 非目标

- 默认强制云 reranker / 云扩写  
- 替换 P3.1 graph signals  
- NER 自动建链：**降为可选增强**；若实现须有 `schema pack` 正则 + 单独验收，未实现不挡 DoD  

## 3. 技术方案

### 3.1 管线与配置

同前（expand → 多臂 → RRF → boosts → rerank → prefilter → signals）。

```yaml
search:
  mode: balanced
  tokenmax:
    expand: true
    expand_n: 2
    rerank: off | local
    rerank_top_n: 20
  hotness:
    enabled: true
    half_life_days: 30
  directory_prefilter: false
  entity_boost: true
  alias_hop: true
```

### 3.2 可观测（强制）

`memory query "…" --mode tokenmax --explain --json` 须能出现（有则填、无则显式 null/省略并文档说明）：

```json
{
  "explain": {
    "mode": "tokenmax",
    "queries": ["…", "…"],
    "rerank": "local|off|skipped",
    "entity_boosts": [{ "path": "…", "slug": "…" }],
    "alias_hits": ["…"],
    "title_phrase": true,
    "hotness": true,
    "directory_prefilter": null
  }
}
```

启发式扩写示例：原查询 + 去停用词变体 / 中英模板，**不调用网络**。

## 4. 验收（须可跑）

| ID | 功能点 | Given / When / Then（口令） |
|---|---|---|
| P53-01 | tokenmax 零 LLM | `llm=off` → `query "重试" --mode tokenmax --explain --json` 退出 0；`explain.queries.length >= 1` |
| P53-02 | 启发式扩写 | 同上且 `expand: true` → `queries.length >= 2`（或文档约定的最小变体数） |
| P53-03 | alias hop | 节点 `aliases: [小名]` → `query "小名" --json` 命中该 path |
| P53-04 | entity boost | `entity create` + 正文提到实体 → 查询实体名时该 path score **高于**无关对照页（夹具固定） |
| P53-05 | title-phrase | 标题含连续短语「支付回调」→ `query "支付回调" --explain` 标记 title_phrase 或分高于打乱词序对照 |
| P53-06 | hotness | 新旧两篇相近相关文档 → 默认新文更靠前；`hotness.enabled=false` 后名次可变化（夹具断言） |
| P53-07 | rerank local | `rerank: local` → explain.rerank=`local`；故意制造词重叠差序 → rerank 后 top1 变化或 explain 记录 scores |
| P53-08 | rerank off/失败 | `rerank: off` 可跑；注入 rerank throw → 仍返回结果且 `rerank=skipped` |
| P53-09 | directory_prefilter | 打开配置 + 两目录夹具 → `--explain` 含预筛信息；召回偏向高分目录（夹具） |
| P53-10 | balanced 无回归 | 默认 mode 下中文门禁/既有 hybrid 测仍绿 |
