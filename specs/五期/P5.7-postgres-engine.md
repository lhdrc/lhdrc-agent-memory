# Spec P5.7 — PostgresEngine（可选索引后端）

| 字段 | 值 |
|---|---|
| ID | P5.7 |
| 状态 | draft |

## 1. 目标（每项须可跑）

1. **`IndexEngine` 抽象**；默认 **pglite** 行为不变  
2. **`index.engine: postgres`** + `DF_MEMORY_DATABASE_URL` 可完成：init 仓 → capture → query → rebuild-index → query  
3. **删库/空 schema 后 rebuild** 从 md 恢复召回  
4. **错误 DSN** → 明确 `E_INDEX`，不静默回退丢数据  
5. **文档 + 一键脚本**：`scripts/dev-postgres.md` 或 `docker compose` 样例，贡献者按文档 10 分钟内跑通 P57-02  

## 2. 非目标

- 多实例共享写  
- CI 默认强制 postgres（CI 仍 PGLite；postgres 为 `test:postgres` 可选 job）  
- 云托管绑定  

## 3. 技术方案

配置同前。提供：

```
docker compose -f scripts/docker-compose.postgres.yml up -d
# 文档给出 export DF_MEMORY_DATABASE_URL=postgres://…
memory init /tmp/pgdemo && 改 memory.yml engine=postgres
memory capture … && memory query … && memory rebuild-index && memory query …
```

pgvector：探测失败则语义臂跳过并 warn，**BM25 query 仍必须可用**。

## 4. 验收（须可跑）

| ID | 功能点 | Given / When / Then（口令） |
|---|---|---|
| P57-01 | 默认 pglite | 不改配置 → 全量 `bun test packages/core/tests` 绿 |
| P57-02 | postgres 主路径 | 按文档起库 → `engine=postgres` → capture 一条 → `query` 命中 path → 退出 0 |

| P57-06 | 脚本存在 | 仓库含 compose 或等价脚本 + README 步骤；审阅可按步骤执行（人工 DoD） |
