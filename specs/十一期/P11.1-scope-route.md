|---|---|

> 记忆召回先选范围，再检索。现网意图只改融合权重。  
> **必须 fallback**：窄范围证据不足 → 再跑（或并入）全仓。禁止无回退级联。

## 1. 目标

1. `classifyIntent` 除调权外，给出 **目录/schema 先验**（零 LLM）。  
2. `search.scope_first=true` 时：先在先验内 hybrid；不够再全仓。  
3. `--explain` / `query_plan` 含 `scope:<intent>:<prefix|off>` 与是否 `expand:global`。  
4. `thinkQuery` 默认走范围选择（经验题先 `experiences/`）。  
5. CLI `query` 默认 **关**（兼容现网序）；配置可开。

## 2. 非目标

- LLM 意图分析 / TypedQuery  
- HierarchicalRetriever 递归下钻与父分传播  
- 把「设计偏好 / 组件约定」写进 core  
- 改 P8.2 层 tie-break 为层权重  
- 默认改变 CLI `query` 排序（除非仓打开 `scope_first`）

## 3. 技术方案

### 3.1 意图 → 先验

`classifyIntent` 结果映射（路径相对 `brains/{brainId}/`，POSIX）：

| intent | 先验 | 过滤方式 |
|---|---|---|
| `experience` | `experiences/` | path 前缀 |
| `person` | `entities/` | path 前缀 |
| `task` | pack 的 issue 根（problem-tree：`sources/*/issues/`） | path 含子串 `/issues/` |
| `relation` | **无先验**（图臂已抬权） | 等同 general |
| `general` | 无 | 全仓 |

lexicon 仍来自 pack `intent_lexicon` + 内置（P3.1）。不新开 intent 枚举，除非测例需要 `task` 打中 issue 路径（已有词表）。

### 3.2 何时算「证据不足」→ expand

窄搜结束后，满足 **任一** 则扩全仓：

- 终榜 hit 数 `< min(limit, 3)`  
- 终榜最高分 `< fused_min * 4`（默认 fused_min=0.05 → 阈值 0.20；可配 `search.scope_expand_max_score`）  
- 窄搜直接抛错 / 空臂 → 当不足

扩全仓：再跑一次 **不加前缀** 的 hybrid（可 skipCache），终榜以全仓为准（不把两次结果简单拼接冒充 top-k）。`query_plan` 记 `expand:global`。

窄搜已够：只返回窄搜终榜；`query_plan` 记 `expand:none`。

### 3.3 配置

```yaml
search:
  scope_first: false          # CLI query 默认
  scope_expand_min_hits: 3
  scope_expand_max_score: 0.20
```

`thinkQuery` **忽略** `scope_first: false`，视为 true（P5.5 think 本就是分空间工具）。`hybridQuery({ scopeFirst: true })` 可单次覆盖。

### 3.4 与目录预筛

`directory_prefilter` 仍是事后按父目录重排。`scope_first` 是 **搜前收缩**。二者可同时开；预筛作用在最终那一次 hybrid 的结果上。

### 3.5 可观测

`query_plan` 增加（有则追加，顺序靠前）：

```
intent:experience
scope:experiences/
expand:none | expand:global
```

`searched_directories`：窄搜阶段的目录；若 expand，用全仓那次的目录（与 P10.4 规则相同）。
