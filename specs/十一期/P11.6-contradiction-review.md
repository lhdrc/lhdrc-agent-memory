> dream 只标记。人审后失效 **fact** 软删。不 rm、不改正文、不 LLM 终审。

## 1. 目标

1. 跨文件对默认 `pending`；两侧可检索；不自动 ×0.85（P11.4 默认关）。  
2. CLI 裁决：`keep_both` | 留 A | 留 B。  
3. 失效侧该条 `facts[i].status = superseded`；页面 `status` 仍 `active`。  
4. 索引 / 检索不再用该 fact 文本（从 FTS/chunk 去掉；磁盘正文不动）。  
5. 裁决写入 sidecar，dream 覆盖 `contradictions.md` **不丢**已审记录。

## 2. 非目标

- LLM 三分类当终审  
- dream 自动判谁过期  
- `--purge` / 整页 `forget`  
- 改 note 正文  

## 3. 技术方案

### 3.1 对身份

P10.3 行：`` `pathA` facts[i] ↔ `pathB` facts[j] ``。  
`pair_id` = 左→右 `sha256(pathA#i|pathB#j).hex.slice(0,16)`。

### 3.2 sidecar

`brains/{brainId}/contradictions-reviews.jsonl` 追加：

```json
{"pair_id":"…","keep":"a"|"b"|"both","at":"ISO","by":"cli:user"}
```

同 `pair_id` 后者覆盖。`keep=a` 留左侧 fact。

### 3.3 写 fact

`keep=a` → 右侧 `facts[j].status=superseded`（已有则幂等）。`both` 不改 facts。禁止改 `## 正文`。

### 3.4 索引

`syncPage`：FTS/chunk 用「正文去掉 superseded fact 字面量 + 其余 facts」。文件哈希仍含 frontmatter（status 变会重切块）。

## 4. CLI

```
memory contradiction list [--json]
memory contradiction resolve <pair_id> --keep a|b|both [--json]
```

list：当前 `## cross-file` 对 ∪ sidecar。无 contradictions 文件 → 空列表。
