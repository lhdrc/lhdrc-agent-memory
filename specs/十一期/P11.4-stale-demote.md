## 1. 目标

1. hybrid 终榜融合后、hotness 前后择一锁定：**hotness 之后**、层 tie-break 之前，读取 `brains/{id}/contradictions.md` 的 **cross-file** 行。  
2. 每一对 pathA↔pathB：较旧者（`pages.updated_at` 较早；缺则 path 字典序后者当旧）分数 × **0.85**（可配）。  
3. 不因降权丢掉 hit；只改序。无文件 / 解析失败 / 无 cross-file → 跳过。  
4. `--explain` 能看到 `stale_demote: [{ path, pair, factor }]` 或空数组。  
5. `local` 哈希档无跨文件行时本项空转（与 P10.3 一致）。

## 2. 非目标

- LLM 三分类 duplicate/supersede/independent  
- 自动 forget / 改 frontmatter / 写 `consolidated_into` 进 L0（本期不扩 dream 格式也可只按 path 对）  
- 把矛盾对当硬过滤（低于阈值直接剔除）  
- 改 intra-file 节语义  
- 乘进 RRF 臂内分  

## 3. 技术方案

### 3.1 解析

读 `brains/{brainId}/contradictions.md`。只认 `## cross-file` 下已有格式（P10.3）：

```
- duplicate cosine=0.96 `brains/.../a.md` facts[0] ↔ `brains/.../b.md` facts[1]
```

抽出两个仓内相对 path。intra-file 忽略。最多 100 对（与写入上限对齐）。

### 3.2 乘子

```yaml
search:
  stale_demote: true          # 默认 true；false 对照 = P10.3 行为
  stale_demote_factor: 0.85   # (0,1]
```

同一 path 出现在多对中：乘子连乘，**下限 0.5**（防叠到 0）。

较新一侧 **不加权**（避免双倍扭曲相关度）。

### 3.3 管线位置

```
… → cosine re-score → graph signals → hotness（P11.2）→ stale_demote → directory_prefilter → rerank → tie-break
```

位置锁在 hotness 后：时效与访问先算，再用矛盾对打破「新旧语义都热」的并列。

### 3.4 P10.3 回归

P10C-06「dream 前后 hybrid 序不变」在 **`stale_demote: false`** 时仍成立。默认 true 后该测例需：要么显式关降权，要么改夹具为「无跨文件对」。**禁止默默删 P10C-06**；更新测例配置即可。
