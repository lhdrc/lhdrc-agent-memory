# Spec P11.7 — L0 capture 审计（memory_diff + node_created）

| 字段 | 值 |
|---|---|

| 状态 | done |
| 依赖 | P2.2 `memory_diff`；P5.4 EventLedger |

| 仓库 | 本仓 `packages/core` |

> capture 落盘与审计 **同一写事务**（`queue.execute` 返回路径含 md + ledger + diff）。

## 1. 目标

1. L0 新建成功：`memory_diff` 一行 `op: create`（`paths_written` 含该 md）。  
2. 同事务：ledger `type: node_created`（`payload.path`）。  
3. `memory changes` 能看见 L0 create。  
4. 失败校验不写幽灵行。

覆盖：`captureNode`、compile 内 `captureWrite`、`importNode`（同为 L0 新建）。

## 2. 非目标

- 通用 `updateNode`  
- ledger 改成表  
- `create` 的 `revert` 自动删 L0（保持 `unsupported_op`；D17 ADD-only）  

## 3. 技术方案

`recordL0Create(repoRoot, brainId, path, by)`：`writeLedgerLine` + `appendMemoryDiff`。  
调用方在已持锁 mutation 内调用，并把返回的 rel 并入 `execute` 路径列表。

`MemoryDiffOp` 增加 `create`。

## 4. 验收

| ID | Given / When / Then |
|---|---|
| P117-01 | `captureNode` note → `listMemoryDiffs` 有 `op=create` 且 path 匹配；`events list --type node_created` 有该 path |
| P117-02 | 一次 `captureNode` 的 queue 返回路径同时含 md、ledger、memory_diff（可通过文件存在断言） |
