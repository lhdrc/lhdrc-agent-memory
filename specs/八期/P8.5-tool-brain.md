## 1. 目标

1. 核心读写工具增加可选参数 `brain`（brainId）：`memory_query` / `memory_read` / `memory_remember` / `memory_job_status`；P8.3 落地后含 `memory_skill`。  
2. 有 `brain` → 覆盖 `config.brainId` / 仓默认，且 **host 按 `repoRoot+brainId` 分实例**（已有 cache key 则复用）。  
3. 跨 brain 必须 `assertBrainScope`（及现有 `authorize`）。trusted local（P4.2 A：`channel: "cli"`）与 CLI 一样可通过；非 trusted 无授权 → 拒绝，不读不写。  
4. `memory_brain` list 增加 sources / 是否为当前默认；create 保持现语义。  
5. 文档一行：同仓多 brain 的 git 历史共享，非密码学隔离；索引按 `brain_id` 分行。

## 2. 非目标

- 会话级「切换默认 brain」（改 cordis config 或写 memory.yml）  
- 一次调用跨 brain 聚合检索  
- 新开 AuthChannel  
- 把 `forget` / `dream` / entity merge 做成 DSH 工具

## 3. 技术方案

### 3.1 解析顺序

```
tool.brain → config.brainId → memory.yml brain_id
```

非法 id（不符合 `00-conventions` brainId 规则）→ `E_USAGE`。  
brain 目录不存在 → `E_NOT_FOUND`（不隐式 `brain create`）。

### 3.2 鉴权

每次解析出 `brainId` 后：

```
authorize(...)
assertBrainScope(authed, brainId)
```

与 CLI `--brain` 同一套函数。失败 → 结构化错误，不碰另一 brain 的文件。

### 3.3 `memory_brain`

| action | 行为 |
|---|---|
| `list` | `{ id, name?, sources: string[], is_default: boolean }[]` |
| `create` | 已有则保持；参数 `id`（及可选 name） |

不在本期做「挂载外部 source」UI。

### 3.4 remember / job 与 brain

`memory_remember` 的 job 写在 `.dfmemory/jobs/{brainId}/`。  
`memory_job_status` 若只给 `task_id`：先在当前默认 brain 下找，找不到再 **不得**扫描其它 brain（防越权）；可另传 `brain`。  
找不到 → `E_NOT_FOUND` / `E_JOB`。
