# Spec P8.2 — 检索分层标注与溯源

| 字段 | 值 |
|---|---|
| ID | P8.2 |
| 状态 | draft |
| 依赖 | P2.1a 混层 RRF；P5.3 检索增强；P2.2 experience 字段；P4.2 A `memory_query` |
| 对应架构 | 08 §7；TODO #6 |
| 仓库 | 本仓 core（过滤/图臂）；插件仓（hit 标注 + prompt 策略） |

> 骨架保持不动：三臂并行召回 + RRF + 模型按需 `memory_read` 原文。  
> 分层只做三件事：让模型知道「这是哪一层」、同相关度下轻微偏好、经验命中能直达 L0。  
> **不做**系统级强制级联（先上层后下层只作文案）。

## 1. 目标

1. `memory_query` 每条 hit 带齐层信息，模型不用猜文件类型：  
   - 已有：`schema_type`（插件 0.4.0）  
   - 补：experience / skill 的 `eta_score`（别名 `eta`）、`support`、`source_paths`  
   - experience snippet **优先 `trigger`**（「何时用」），不足再回退 body 截断  
2. 可排除侧车：`*.overview.md`（及若存在的 `*.abstract.md`）默认不占插件 query 名额；原文仍可 `memory_read`。  
3. 可排除/只含 `schema_type`：core 增加 `excludeSchemaTypes`；图臂补 `schemaType`（及排除），避免 `type=` 过滤时图臂命中被二次丢光。  
4. prompt section 写两段式策略（先 `type=experience` 试可执行知识 → 不够再全量 → 沿 `source_paths` 回读）。  
5. 同相关度 tie-break **可选**且权重极小（±0.01 级），**不得**压过 RRF 相关度。

## 2. 非目标

- 改三臂集合或 RRF `k=60`  
- 系统强制「先 skill/experience 再 L0」的级联查询  
- 自动闭环（query 完再自动 read）  
- 把 overview 从磁盘删掉或停止 `layers refresh`  
- 改 CLI `query` 默认 JSON 形状到不兼容（新字段只增不删；侧车排除 CLI 默认关）

## 3. 技术方案

### 3.1 core：`HybridQueryOptions` 增量

```ts
excludeSchemaTypes?: string[];   // 与 schemaType 互斥：同时传 → E_USAGE
excludeSidecars?: boolean;       // true：path 匹配 /\.(overview|abstract)\.md$/ 的 hit 丢掉
```

过滤时机：各臂取回后、RRF 前（图臂也必须能按 type 过滤，见 §3.2）。  
`schemaType` 仍是「只保留该类型」（P2.1a）。

CLI：

```
memory query "…" --type experience
memory query "…" --exclude-type skill
memory query "…" --exclude-sidecars
```

`--type` 与 `--exclude-type` 同时出现 → `E_USAGE`。  
CLI 默认 **不**开 `--exclude-sidecars`（兼容）。插件 `memory_query` 默认 `excludeSidecars: true`，且默认 `excludeSchemaTypes: ["skill"]`（与 P8.3 一致；显式 `type=skill` 时不加排除）。

### 3.2 图臂 `schemaType`

`graphArmDetailed` / `GraphArmOptions` 增加 `schemaType?`、`excludeSchemaTypes?`。  
SQL 在从 `pages` 取回邻接文档时加 `schema_type` 条件（与 BM25/语义臂同一列）。  
无匹配 → 空臂，fail-open，不把未过滤图 hit 丢进融合后再删（避免名额浪费）。

### 3.3 hit 标注（插件为主，core 可给原料）

`hybridQuery` 今日 hit 已有 path/title/snippet/score。experience 的 `trigger` / `eta_score` / `support` / `source_paths` 在文件 frontmatter，**不在** pages 主列。

锁定：

- 插件（或 core 一个只读 helper `annotateHits(repoRoot, hits)`）对 `schema_type ∈ {experience, skill}` 的 path **读 frontmatter**（已有文件权威；失败则省略字段，不整次失败）。  
- 不得为标注再跑一遍混合检索。  
- 读失败 fail-open。

插件返回 hit 形状（字段可空）：

```json
{
  "path": "brains/default/experiences/….md",
  "title": "…",
  "score": 0.42,
  "snippet": "<trigger 优先>",
  "schema_type": "experience",
  "eta_score": 0.5,
  "support": 2,
  "source_paths": ["brains/default/sources/default/notes/….md"]
}
```

`source_paths` 必须是仓根相对路径，便于直接 `memory_read`。

snippet 规则（experience）：

1. frontmatter 或正文 heading `trigger` 非空 → 截断作 snippet  
2. 否则现有 body 截断  

skill 的 snippet 同期可用 `trigger`（P8.3 查找面也会用）。

### 3.4 tie-break（可选，低优先）

仅当 **最终分并列**（或分差 `< 0.01`）时：`skill > experience > L0(note/decision/lesson) > 其它`。  
实现：融合后稳定排序的 comparator，**不加**进 RRF 权重公式。  
无并列则顺序与现网一致。本项不阻塞 DoD；做了要有 P82-08。

### 3.5 Agent 策略（零核心代码）

`df-memory` section 增加（大意，不必逐字）：

- 回忆事实 / 决策：`memory_query`  
- 要可执行「以后怎么做」：可先 `type=experience`；命中后看 `eta_score`/`support`；要核事实则 `memory_read` `source_paths`  
- 经验是压缩，可能失真；L0 是依据  
- 规则 / 必须遵守的流程：走 `memory_skill`（P8.3），不要靠默认 query 撞 skill  

**禁止**在 core 里做成「第一次 query 自动再查一层」。

## 5. 验收

| ID | 功能点 | Given / When / Then |
|---|---|---|
| P82-01 | exclude type | 库中有 skill + note；`hybridQuery({ excludeSchemaTypes: ["skill"] })` → path 集合不含 `/skills/` |
| P82-02 | type 互斥 | 同时传 `schemaType` 与 `excludeSchemaTypes` → `E_USAGE` |
| P82-03 | 侧车 | 同题 L0 + `*.overview.md` 均在索引；`excludeSidecars: true` → 无 overview path；`false` → 可有 |
| P82-04 | 图臂 type | `type=experience` 时图臂不返回 `schema_type≠experience` 的 path；explain 里 graph 臂可空 |
| P82-05 | 标注 | 一条 experience 含 `trigger`/`eta_score`/`source_paths`；query `--json`（或插件 hit）带齐；snippet 含 trigger 原文子串 |
| P82-06 | 标注 fail-open | experience 文件缺字段或读失败 → hit 仍返回 path/score，扩展字段省略 |
| P82-07 | 插件默认 | 未传 `type` 的 `memory_query` 不含 skill path、不含 `*.overview.md` |
| P82-08 | tie-break（可选） | 两 hit 分差 `<0.01`、一 experience 一 note → experience 更前；分差 `≥0.05` 时相关度高者仍前 |
| P82-09 | section | 文案含「经验沿 source_paths 回读」与「skill 走独立工具」 |
