# Spec P7.2 — Distill / refine 真路径

| 字段 | 值 |
|---|---|
| ID | P7.2 |
| 状态 | ready |
| 依赖 | P7.1、P2.2、P3.2、P5.6 |
| 对应架构 | 08 §6.4、D17；P2.2 管线已有，生产 LLM 此前空转 |

> 管线（预筛 → `judgeDistill` → create/merge/supersede/noop → `memory_diff`）**不改**。  
> 本期：生产 provider 真决策；compile **放锁后**可懒蒸馏；成熟则自动写 **candidate** skill；`eval --distill` 跑 refine。

## 1. 目标

1. `llm.provider=openai`（或测试注入）时：`memory refine` 与 `dream --phases 3` 按 P2.2 映射写 experience；`written≥1` 在 mock create 下可复现  
2. `provider=off` 或 `kill_switch.distill` 或 `llm.distill=false`：整批 skip，CLI 明确提示，**不**假装成功蒸出经验（`written=0`，exit 0 可保留，但 `--json` 含 `skipped_reason`）  
3. 懒蒸馏：无 `--path` 时只处理 **尚未出现在任何 active experience 的 `source_paths`** 的 L0（增量）；已蒸过的不重复 judge  
4. `compileSession` **成功且已放锁** 后：未蒸 L0 数 ≥ `distill.lazy_min_sources`（默认 **5**；`≤0` 关闭）则本进程调用同一 `refineSource`（无 path）  
5. 上述 refine（自动或手动）结束后：对够熟的经验簇 **自动** `crystallizeExperiences` → SKILL.md `status=candidate`；**不** `activate`；同名已存在则跳过。`auto_crystallize=false` 或 `provider=off` 则跳过自动结晶  
6. `eval --distill` / `bun run eval:distill`：**先跑** `refineSource`（mock complete → create），再测检索 uplift；禁止只手写 fixture experiences 当「蒸馏有效」  
7. skill 结晶：openai 下 `refineExperience` 失败 → **不**静默启发式；记 `errors`；off 下人手 crystallize 仍启发式  
8. `noop` diff **仅当** judge 真返回 skip/none  

## 2. 非目标

- 改 D17 词表映射  
- 扩 dream 九段  
- 蒸馏热路径改/删 `sources/`  
- 把 refine **塞进** compile 的 `queue.execute`（锁内禁止调蒸馏 LLM）  
- 自动 `skill activate`  
- `capture` 成功后自动蒸馏  

## 3. 技术方案

### 3.1 refine 入口

`refineSource` 已有。补：

```
1. 解析 LLM：opts.llm ?? createLLMProvider(cfg)
2. if !isDistillEnabled && !opts.llm → return { written:0, skipped:N, skipped_reason:"llm_off"|"kill_switch"|"distill_false" }
3. collectSourcePaths
4. 懒过滤：去掉 sourceRel 已在某 active experience.frontmatter.source_paths 里的
   （normalize 为 brain 相对 `sources/…` 再比）
5. 对剩余逐条 refineOneSource（现逻辑）
6. --json：{ written, skipped, skipped_reason?, paths, lazy_omitted }
```

`--path` 显式指定时 **不做**懒过滤（允许重蒸该源；merge/skip 由 judge 决定）。

`dream --phases 3` 调同一 `refineSource`（无 path = 懒全量）。

CLI：`memory refine [--path] [--json]` 必须把 `skipped_reason` 打到 stderr 或 json（off 时用户能看出不是「蒸了 0 条因为没内容」）。

### 3.2 openai 下 create 路径

P7.1 使 `judgeDistill` 可返回 create。`refineOneSource` 已在 create 时调 `refineExperience`。  
回归：mock `_DISTILL` 先返回 create JSON；若同一 blob 不够两次不同 purpose，允许：

- 一次 `complete` 日志两条 purpose=distill（judge + refine）  
- 或 `DF_MEMORY_MOCK_COMPLETE_DISTILL` 为 **JSONL 两行**（第一次 judge、第二次 refine）——实现任选，测试锁一种并写在 `p72_distill_live.test.ts` 注释  

推荐：EnvMock 对 `distill` 若文本是 JSONL，按调用序取行；否则整段重复用于每次 `complete`。judge 与 refine 形状不同时必须用 JSONL。

### 3.3 eval:distill

改 `evals/distill.ts`：

```
capture fixture notes
scoreQuestions → withoutExperience
注入 mock LLM（create + refineExperience 合法 JSON）
refineSource(全部 notes)
scoreQuestions → withExperience
写 receipt：{ without, with, used_refine: true, written }
```

删除（或降为对照开关）「手写 `writeExperience` 当蒸馏」的默认路径。  
`--fixture-experiences` 可选：仍写入工经验，作对照；默认关。  
无 mock / provider=off：exit 非 0，提示 `DF_MEMORY_MOCK_COMPLETE_DISTILL` 或 openai key（评测仓库 CI 设 mock）。

### 3.4 skill 结晶

`crystallizeExperiences`：

```
openai 或 opts.llm：
  refineExperience 成功 → 用模型结果
  抛 E_DISABLED / E_LLM → 不写该 skill；计入 errors[]；不得用 heuristicSkillFromCluster 顶替
off：
  不调 refineExperience；启发式写 skill（仅人手 CLI；自动结晶跳过）
```

`--json`：`{ written, skipped, errors:[{ cluster, code, message }] }`。

自动结晶：`maybeAutoCrystallize` 在 `refineSource` 返回后调用（含 compile 触发的那次）。成熟判定仍 P3.2。只写 `candidate`。

### 3.5 写入时机与配置

```yaml
distill:
  lazy_min_sources: 5   # compile 成功后；≤0 不自动蒸
  auto_crystallize: true
```

init 写入默认值。`remember --buffer` 仅 append 时 **不**走这段。

```
compileSession 成功
  → 放锁
  → countUndistilledL0 >= lazy_min_sources ?
       yes → refineSource()（懒）→ maybeAutoCrystallize()
       no  → 结束
```

experience **不是** compile job 内写的。索引：L0 在 compile hook 已增量同步；experience/skill 各自写队列 hook 再增量，**不**全量 `rebuild-index`。

## 4. CLI

```
memory refine [--path <rel>] [--json]
memory dream --phases 3 [--json]
memory skill crystallize [--json]
bun run eval:distill
memory eval --distill [--json]
```

`remember --json` 在触发自动蒸馏时增加 `distill?: { written, lazy_omitted, crystallized?: string[] }`（未触发则省略）。

`provider=off`：refine `--json` 含 `skipped_reason`，`paths=[]`，exit 0。compile 后自动蒸馏同样 skip，不影响 L0 已成功。
