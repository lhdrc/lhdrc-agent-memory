## 1. 目标

1. `memory inbox retry <sessionId>`：与 `ingest --adapter session --retry <id>` **同一实现**  
2. `memory revert <diffId>` 支持：`experience_create`（已有 archive）、`experience_supersede`（已有恢复 active）、**`experience_merge`（快照还原）**、**`skill_create`（archive）**、**`noop`（成功空操作）**  
3. 仍不支持的 op → `unsupported_op`，`--json` 含 `op`，stderr 列出支持列表  
4. merge 时 `memory_diff` 必须带可还原快照（见 §3.2），旧条目无快照 → 仍 `unsupported_op`（不编造内容）  

## 2. 非目标

- `inbox` 变成编辑器 / 重放任意 messages 为 L0  
- revert `experience_merge` 用 git  
- revert `skill_activate` / `skill_outcome` / `skip_duplicate` / `abstract_update`（可后续）  
- 给 session 适配器加 `--no-extract`（保持 P6.3：整场会话必须 compile）  

## 3. 技术方案

### 3.1 inbox retry

```
memory inbox retry <sessionId> [--json] [--dry-run]
```

CLI 调现有 `compileSession({ sessionId, dryRun })`。help 不再写「仅 list」。  
未知子命令：提示 `list | retry`。  
P7.3 若已落地：`inbox end` 可在本文件实现为 `endSession` 别名（可选；有则验收 P75-06）。

### 3.2 revert 快照

扩展 `MemoryDiffEntry.revert`：

```ts
revert?: {
  action: "archive_path" | "restore_snapshot" | "none";
  path?: string;
  snapshot?: {
    procedure?: string;
    boundary?: string;
    body?: string;
    status?: string;
  };
};
```

`refineOneSource` 在 `experience_merge` **写盘前**读旧 experience，写入 `revert: { action: "restore_snapshot", path, snapshot }`。

revert 映射：

| op | 行为 |
|---|---|
| `experience_create` | 已有：`status=archived` |
| `experience_supersede` | 已有：`status=active` |
| `experience_merge` | `restore_snapshot`：写回 procedure/boundary/body（经 `validateWrite` / patch）；无 snapshot → `unsupported_op` |
| `skill_create` | `archive_path`：skill `status=archived`（或目录内 SKILL.md status） |
| `noop` | `ok:true`，`reason:already_noop`，不写文件、不追加新 diff（或追加 `op=noop` `decision.revert_of` 任选；测试锁「不写文件」） |
| 其他 | `ok:false`，`reason:unsupported_op` |

skill_create 写入 diff 时补 `revert: { action: "archive_path", path }`（今日可能缺失，结晶侧一并补）。

回滚本身追加一条 diff（create→supersede 已有）；merge 还原追加 `op=experience_merge` 或新 op `experience_restore`——**用 `experience_merge` + `decision.revert_of`**，避免扩 enum 也可。测试断言 `revert_of`。

## 4. CLI

```
memory inbox list [--json] [--status pending|failed|done]
memory inbox retry <sessionId> [--json] [--dry-run]
memory revert <diffId> [--json]
```

`--json` revert 失败：`{ ok:false, reason:"unsupported_op"|"not_found", op? }`，exit 2（not_found / unsupported）与今 CLI 对齐；若今日 exit 0+打印，**改为非 0** 以免脚本当成功（若改退出码，在 help 写明；单测锁 exit code）。

查现网 `revertCommand`：成功打印 `reverted …`；失败应 `E_NOT_FOUND` / `E_USAGE` 而非静默。本期统一：

- `not_found` → `E_NOT_FOUND` exit 2  
- `unsupported_op` → `E_USAGE` exit 2  
- `already_noop` → exit 0
