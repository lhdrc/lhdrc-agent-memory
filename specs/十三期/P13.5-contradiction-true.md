## 1. 目标

1. 桶：`倒排 fts + links + entity_registry` 按 `entity_slug` 分桶，`k=5`。  
2. 快路径：桶内 `cosine≥0.95→duplicate`。  
3. 值冲突：`isObjectValueConflict + 否定词` 二筛。  
4. LLM：灰区 `0.92-0.95` 批量10对 `duplicate|supersede|independent`。  
5. 落盘：`contradictions.md` 标 `contradiction supersede a->b` + 预填 `facts.supersedes`，人审 `keep a|b` 才 `superseded` 入索引剔除 `*0`。  
6. 增量：`dream --phases 4` 仅新 `facts` + 同桶邻居。

## 2. 非目标

- 全量 `O(n²)` LLM 每对判
- `local` 强行 LLM
- `k>5`、自动 `purge` 整篇
