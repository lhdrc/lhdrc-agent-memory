> 不新增 `KNOWN_LINK_TYPES`，只补检索侧 `TEMPLATES` 使 `建≡检索`。

## 1. 目标

补 `decided / produced_by / belongs_to / invested_in / advises` 5 种动词的检索模板，中英各一，使 `links` 10 种已建边均可 `relational` 精准问。

## 2. 非目标

- 新增边类型、改 `DEFAULT_VERBS`
- 动 `signals / prefilter / rrf`
- page-type 绑定边

## 3. 技术方案（对标 `graph/link-extraction.ts:20 KNOWN_LINK_TYPES` 10种 + `35 DEFAULT_VERBS` 8正则 / `index/sync.ts:25 verbPatternsForRepo` / `retrieve/graph.ts:22 TEMPLATES` 7模板 + `161 hitsFromSeeds` / `schema.sql:43 links`）

`retrieve/graph.ts:22 TEMPLATES` 增 5 组（各中英一，复用现 `STOPWORDS:33` / `needleMatchesQuery:68` 门限）：

| type | 模板（新增） | 建侧来源 |
|---|---|---|
| `decided` | `谁决定了(.+)` / `who decided (.+)` | `DEFAULT_VERBS /决定/decided/` 已建 |
| `produced_by` | `谁产出了(.+)` / `who produced (.+)` | `产出/produced` |
| `belongs_to` | `(.+)属于(.+)` / `(.+) belongs to (.+)` | `属于` |
| `invested_in` | `谁投资了(.+)` / `who invested in (.+)` | `投资/invested` `P10.2` 新增 |
| `advises` | `谁是(.+)顾问` / `who advises (.+)` | `顾问/advises` |

`hitsFromSeeds:161` 已 `type=$3` 过滤；`collectAdjacencySeeds:127` 仍兜底；`compileExtraVerbs(pack.extra_verbs)` 自动透传 `syncLinksForPage` → `links` 落表（`TODO #8` 闭环），检索不增 `KNOWN_LINK_TYPES`。

参考：`gbrain/src/core/engine.ts:127 LinkBatchInput` 的 `link_kind` 区分 `plain vs typed_ner`（本期不做，仅保持 `source=mention` 复用）。
