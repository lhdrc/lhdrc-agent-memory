## 1. 目标

补 `decided / produced_by / belongs_to / invested_in / advises` 5 种动词的检索模板，中英各一，使 `links` 10 种已建边均可 `relational` 精准问。

## 2. 非目标

- 新增边类型、改 `DEFAULT_VERBS`
- 动 `signals / prefilter / rrf`
- page-type 绑定边

## 3. 技术方案

`retrieve/graph.ts:22 TEMPLATES` 增：

| type | 模板 |
|---|---|
| `decided` | `谁决定了(.+)` / `who decided (.+)` |
| `produced_by` | `谁产出了(.+)` / `who produced (.+)` |
| `belongs_to` | `(.+)属于(.+)` / `(.+) belongs to (.+)` |
| `invested_in` | `谁投资了(.+)` / `who invested in (.+)` |
| `advises` | `谁是(.+)顾问` / `who advises (.+)` |

`hitsFromSeeds:161` 已支持 `type=$3` 过滤；`extra_verbs` 自动透传。
