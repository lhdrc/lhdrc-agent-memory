> 文章级返回不变。只动 `pages` 的 BM25 臂（`retrieve/query.ts:59` / `index/sync.ts:105` / `schema.sql:3`），`chunks` 仍仅服务语义臂。

## 1. 目标

1. `GIN` 物化：`GIN(to_tsvector('simple',coalesce(fts_title,'')))` + `fts_body`，或存 `tsvector` 列增量更。  
2. 统一清洗 `cleanForIndex(text)`：复用 `stripCodeBlocks` + 去 `[]()/#|>` + NFKC/lower + 空白归一，`indexBodyText` 之后再洗才写 `fts_*/bigrams`。  
3. `bigram` 去噪：过滤跨词 `bigram`（频次/词典）。  
4. 长度归一：`score /= len^β`。  
5. 短语：`phraseto_tsquery` 或 `position` 倒排加分。

## 2. 非目标

- 自建 posting list、切块级 BM25、`jieba` 重分词
- 把清洗结果写入 `content_hash`（`content-hash.ts:20` 白名单外）
- 把 `chunks` 拉进 BM25

## 3. 技术方案

### 3.1 物化（对标 `index/schema.sql:3` / `index/engine.ts:123 ensureSchema`）

- 新增物化列或 `GIN` 索引（二选一，优先 `GIN` 不改行）：`CREATE INDEX IF NOT EXISTS pages_fts_title_gin ON pages USING gin (to_tsvector('simple', coalesce(fts_title,'')))`，`fts_body` 同理；或存 `tsvector` 列 `fts_title_tsv tsvector` 在 `sync.ts:148` `INSERT ... ON CONFLICT` 时 `to_tsvector('simple', clean)` 同步。
- 迁移：`engine.ts` 加 `ALTER TABLE pages ADD COLUMN IF NOT EXISTS fts_title_tsv tsvector` / `ADD INDEX`，`PGLite` 与 `postgres` 双引擎共 `schema.sql`，`ensureSchema` 幂等；`rebuild-index` 全量回填。
- 查询：`retrieve/query.ts:72 bm25Query` 将 `ts_rank(to_tsvector('simple',fts_title), plainto_tsquery(...))` 改 `ts_rank(fts_title_tsv, plainto_tsquery(...))` 或 `WHERE fts_title_tsv @@ plainto_tsquery` 走 `Bitmap Index Scan`，保留 `title_ngrams/body_ngrams` `2.0/0.8` 权重与 `position(lower(title)) +3.0 aliases` 兜底。

### 3.2 清洗（对标 `index/sync.ts:57 indexBodyText` / `graph/link-extraction.ts:52 stripCodeBlocks` / `retrieve/ngrams.ts:3 bigrams` / `frontmatter.ts:11 parseFrontmatter`）

- 新增 `cleanForIndex(text, mode: 'bm25'|'semantic')`：`NFKC + lower + 全半角` → `stripCodeBlocks`（`bm25` 用空格替、`semantic` 保留首行注释/函数名）→ 去 `![alt](url)→alt`、`[a](url)→a`、`[[wikilink]]/@slug`留文本、`#*>-` 行首、`|` 表格线 → `\s+→" "` → `indexBodyText` 的 `superseded` 剔除之后再洗，避免已废 `fact` 进 `fts`。
- 调用点：`sync.ts:142 titleNgrams=bigrams(cleanForIndex(title,'bm25'))`、`bodyNgrams=bigrams(cleanForIndex(indexBody,'bm25'))`、`fts_title/fts_body = cleanForIndex(...)`；`chunks` 仍 `chunkText(cleanForIndex(indexBody,'semantic'))` 句界优先，不进 `content-hash.ts:49 pickSemanticFrontmatter` 白名单（`content_hash` 不变）。

### 3.3 去噪/归一/短语（对标 `retrieve/query.ts:75` 权重 `3.0/1.0/2.0/0.8` / `hybrid.ts:665 fuseHybridArms` / `distill/d17-map.ts:36 heuristicAbstract`）

- 去噪：`title_ngrams` 过滤跨词 `bigram`（频次<2 或 `jieba` 词典切分后跨词边），`bigrams.ts` 新增 `filterCrossWord(bigrams, dict)`，`index/sync.ts` 入库前滤。
- 归一：`query.ts:82` 终分前 `scoreNorm = score / pow(lenChars, 0.3)`，`lenChars = length(coalesce(body_text,''))`，`hybrid.ts` 透传 `len` 供 `RRF rescale` 后校正，长文垄断回归 `P93-02` 同款用例。
- 短语：`phraseto_tsquery('simple', q)` 与 `plainto_tsquery` 双路 `ts_rank` 加权 `+0.5*phraseRank`，或保留 `position(lower(title))` 精确短语兜底。
- 参考：`codex-rs/memories/write/templates/memories/consolidation.md` 字面保留原则，避免清洗把 `error string` 改写。
