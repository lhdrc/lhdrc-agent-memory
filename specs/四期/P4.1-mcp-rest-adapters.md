# Spec P4.1 — MCP、REST 与 Agent 适配器

| 字段 | 值 |
|---|---|
| ID | P4.1 |
| 原 ID | P2.3（已迁出二期；**最后做**） |
| 状态 | draft |
| 依赖 | M2, P2.1a；建议 P2.2（refine）、P3.2（skill 注入）、P3.3（AccessControl） |
| 对应架构 | 08 §10、§12、D7、D16 |

## 1. 目标

1. `@df-memory/mcp`：MCP Server 暴露工具面  
2. REST 子集（可挂 `memory serve`）  
3. 至少一个适配器：**Claude Code**（SessionStart 注入 + CLAUDE.md 协议）  
4. Agent **不**直接读记忆仓文件作为主路径（文档与示例强制走工具）  
5. 鉴权 **复用 P3.3** `AccessControl`（若尚未实现 P3.3：仅允许 trusted local / 单用户 token 桩，并在文档标明）  

## 2. 非目标

- 全量 harness 适配器（Codex/OpenCode 可只给 example 草稿）  
- OAuth；鉴权用 API token 字符串（与 P3.3 对齐）  

## 3. MCP 工具契约

| 工具 | 参数 | 映射 |
|---|---|---|
| `memory_find` | `query`, `limit?`, `mode?`, `source?` | retrieve |
| `memory_read` | `path`, `layer?: l0\|l1\|l2` | read |
| `memory_grep` | `pattern`, `source?` | BM25/关键词 |
| `memory_list` | `path?`, `depth?` | tree |
| `memory_remember` | WRITE_FORMAT 字段集 | capture 队列 |
| `memory_forget` | `path`, `purge?:false` | forget |
| `memory_refine` | `source?`, `path?` | refine（需 P2.2；未实现返回明确错误） |

所有写工具：`validateWrite` 失败返回结构化 JSON error（便于模型重试）。

传输：stdio MCP（默认）；可选 SSE 后置。

## 4. REST 子集

| Method | Path | 说明 |
|---|---|---|
| GET | `/health` | `{ok:true, version}` |
| POST | `/api/memory` | body=CreateNodeRequest |
| POST | `/api/retrieve` | body=RetrieveRequest |
| GET | `/api/memory/*path` | read |
| GET | `/api/tree` | query path, depth |
| POST | `/api/refine` | 可选 |

鉴权头：`Authorization: Bearer <token>`（对接 P3.3；未实现时 token 配在 memory.yml，单用户）。

错误体：`{ "code": "E_VALIDATION", "errors": [...] }`。

## 5. Claude Code 适配器

目录：`packages/adapters/claude-code/` + `examples/claude-code/`

交付物：

1. `CLAUDE.md` 片段：声明必须用 MCP 工具读写记忆  
2. `hooks/session-start.sh`（或 JSON hook 配置）：调用 `memory query`/`memory_find` top-3 经验/标题，写入会话上下文文件  
3. README：如何把 MCP server 注册进 Claude Code  

注入优先级（有 P2.2/P3.2 时）：Skill > experience > 无则仅返回空并提示冷启动（允许 L0 摘要兜底——若开启 `inject.allow_source_l0: true`）。

## 6. CLI

```
memory serve --mcp          # stdio MCP
memory serve --http :8787   # REST
```
