## Spec 文档约定

每份 Spec 必须包含：

- **目标 / 非目标**
- **依赖**（前置 Spec）
- **包与模块落点**
- **数据模型 / 文件格式**（字段级）
- **算法或状态机**（步骤级）
- **CLI 或 API 契约**（参数、退出码、错误码）
- **验收用例**（Given/When/Then，可自动化）
- **完成定义（DoD）**

状态字段：`draft` | `ready` | `in_progress` | `done`。
