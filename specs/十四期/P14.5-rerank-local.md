# Spec P14.5 — rerank local 加强（开关默认 off + cross-encoder 插槽设计）

| 字段 | 值 |
|---|---|
| ID | P14.5 |
| 状态 | todo |
| 依赖 | P9.3（融合/cosine remix 不动）；`tokenmax.rerank` 开关沿用（`embed/types.ts:77` 默认 `off`） |
| 对应架构 | fail-open（无模型/无 Key 降级）；设计文档 `2026-09-07-vector-retrieval-design.md` §4 |
| 仓库 | 本仓 `packages/core` |

> 纯查询时模块，不碰表、不碰索引、不重建。现状 local 与 BM25 `position` 兜底投的是同一票（短语 + 二元）；本期做实邻近度与多证据，cross-encoder 只占插槽不装权重。

## 1. 目标

1. local 加强（`retrieve/rerank.ts`）：邻近度（query 词在正文共现窗口内的距离）+ 多证据加权（多 chunk 命中同一篇加分，呼应 max-pool 只取 max 的亏）+ 保留标题/首段加权；仅重排 topN（`rerank_top_n` 默认 20）。
2. 开关沿用：`off/local/model`，默认 `off`（默认链路零影响）；`model` 仅 tokenmax 模式生效；`conservative` 不开语义臂不动。
3. cross-encoder 插槽设计（不含权重）：抄 P9.2 三档（`model/local/off`）+ 缺权重 `E_DISABLED` + 降级 local + 可观测（`--explain` 已有 `rerank:` 状态位复用）；`rerankFn` 注入点转正为正式接口。
4. 效果用 `eval:mini` A/B 度量（开/关对照）。

## 2. 非目标

- 装 cross-encoder 权重（版本级，另排）
- API rerank / LLM listwise（有 Key 才开的增强档，另排）
- 动融合权重基线

## 3. 技术方案（对标 `retrieve/rerank.ts:5` `localRerankScore` / `retrieve/hybrid.ts:762-805` 重排段 / `embed/types.ts:26-27,77-78` 开关）

| 项 | 做法 | 文件 |

| local 加强 | 邻近度 + 多证据 + 标题/首段；topN 内重排 | `retrieve/rerank.ts` |
| 开关/状态 | 沿用；`--explain` 透 `rerank` 贡献 | `retrieve/hybrid.ts` + `embed/types.ts` |
