> 原先 800 硬切（超长段落按下标腰斩、无重叠）。本期只换切分函数，下游逻辑一行不动；存量不管，一次全量 `rebuild-index` 生效。

## 1. 目标

1. 移植 normalize：去 `\r`、URL 断行修复、CJK 软换行合并（`商\n保通 → 商保通`；跨空行与列表项开头不合并）。
2. 边界回溯：换行 → 中文句末（`。！？`）→ 英文句末（`.!?` 且后接空白/结尾，防切 URL 域名点）；回溯距离 ≤ overlap；回退过头强制推进（防重复/停滞）。
3. overlap + 碎尾合并：相邻片重叠；尾巴 < `minChars` 并回上一块。
4. 围栏 guard：扫描跟踪 ` ``` ` 状态，不从代码围栏中间切（笔记代码多，十几行，值）。
5. 参数：`maxChars=800` 不变（一次只动切法不动体量），`overlap=100`，`minChars=200`；`eval:mini` A/B 后再调。
6. 纯 TS 无依赖；调用点唯一（`sync.ts:150`）；chunks 按 `${path}#${i}` 全删全插（`sync.ts:174-182`），自洽；`chunker` 版本进 `EmbeddingMeta` 定稿为做（无版本视为旧库 → mismatch 提示 rebuild）。

## 2. 非目标

- 标题分节/表格/图片块/父子回跳（chunk 二期）
- 改下游逻辑（`semanticArm`/RRF/cosine/rerank 全在篇级，不碰）
- 改 `content_hash`（切分只影响派生 chunks 表）
