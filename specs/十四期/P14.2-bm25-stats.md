> 真 BM25 要的 `tf/df/N/dl/avgdl` 表里一个没有。本期只上 `dl + N/avgdl`（半 BM25，有长度支点）；`terms` 词项表真 IDF 为阶段二，另排期。

## 1. 目标

1. `pages` 加 `doc_len INT`：篇长 = 中文二元数 + 英文词数（P14.1 的 `tokenizeMixed` 输出长度），`syncPage` 随 upsert 同行写，零额外写。
2. 新增 `corpus_stats` 单行表 `{n, avgdl, updated_at}`：`schema.sql` + `ensureSchema` 幂等，双引擎共用。
3. 重算点：`compile/session.ts` 一批 note 写完（`historyEntries` 落盘处）顺手重算；人手单篇 `capture` 只打脏标，下次 flush 捎带；`rebuild-index`/`dream` 全量重算。
4. 读写不互斥：写走 `WriteQueue`，读另开连接；单行 UPDATE 原子，统计天然 stale 可读（`N/avgdl` 小差只动小数点后几位，不等刷完也能查）。
5. 打分：`TF项 = tf*(k1+1)/(tf + k1*(1-b+b*dl/avgdl))`，`k1=1.2、b=0.75` 锁死；`tf` 暂用现有 `ts_rank` 输出代入（阶段二换真 `tf`）。

## 2. 非目标

- 改 `RRF k=60`、改 P13.1 六路权重基线

## 3. 技术方案（对标 `index/sync.ts:106` `syncPage` / `index/schema.sql` / `index/engine.ts:123` / `compile/session.ts:565` / `retrieve/query.ts:86`）
