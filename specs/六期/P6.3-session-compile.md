# Spec P6.3 — 会话编译器

| 字段 | 值 |
|---|---|
| ID | P6.3 |
| 状态 | done |
| 依赖 | P6.1、P6.2、M2、P5.1（cosine 零件）、P3.1 |
| 对应架构 | 08 §6.3 prompt 即规格；六期选择 1–4；**会话产品必须有 LLM API** |

> **摄入入口是 `compileSession`，不是 `capture`。**  
> 加工原文 = **本文件逻辑 + `session-extract-v1.md`**，经 `complete()` 填槽。无可用模型时会话摄入 **不可用**（`E_DISABLED`），不以启发式冒充产品。

## 1. 目标

1. `compileSession` 内部 archive + 提取 + 一次 `queue.execute`  
2. 提取只走 `complete(purpose=compile)` + [`session-extract-v1.md`](../../packages/core/resources/session-extract-v1.md)  
3. 无 provider / 无 key / kill-switch / cost cap → `E_DISABLED`，inbox `failed`，零次 `captureWrite`  
4. 默认写前去重；linkify；单 job 写盘  
5. 送模型前剥离 `<df-memory-context>`（P6.5 注入块不得再变成 L0）  
6. 测试 **mock `complete`**，CI 不打真实 API  

## 2. 非目标

- 启发式 Extractor 当产品路径（已取消）  
- 撤 `memory capture`；改 P5.8  
- `captureWrite` 自己持锁或 enrich / `layers.auto`  
- F11 / F12；持锁调 LLM  

`--no-extract` 仅 `remember`：跳过 `complete`，当一条 `note`（已是结论）。整场 `ingest --adapter session` 带该 flag → `E_USAGE`。

## 3. 技术方案

### 3.1 入口

```ts
compileSession(opts: {
  repoRoot: string; brainId: string; sourceId: string; createdBy: string;
  pack: SchemaPack; queue: FileMutationExecutor;
  turns?: Turn[];          // 新场：内部 archiveSession
  sessionId?: string;      // retry：只 load
  dryRun?: boolean;
}): Promise<CompileResult>
```

新场必须有 `turns`；retry 必须有 `sessionId`。两者都给 → `E_USAGE`。  
`dry-run`：不 archive、不 execute；**仍调** `complete`（预览与真跑一致；测试 mock）。

`sessionId` 格式：`YYYYMMDDThhmmss-<8 hex>`，仅 `[a-zA-Z0-9_-]`。

### 3.2 加工逻辑（锁外 → 一次 job）

```
1. 剥 turns 里 <df-memory-context>…</df-memory-context>
2. system/tool 不送模型；tool 已在 inbox 截断
3. user+assistant 合计 > compile.max_input_chars（32000）→ 丢最早 turn，truncated=true
4. dryRun? 跳过 archive : archiveSession（内部）
5. status=done → 返回 kept_paths
6. 已有 extracted.json 且未 done → 跳过 complete（retry 不重跑模型）
7. 否则：
     无可用 LLM → markFailed E_DISABLED，无 extracted.json
     prompt = session-extract-v1.md + 编号 turns
     complete({ purpose:"compile", system: prompt 的规则段, prompt: turns })
     剥 ```json 围栏 → JSON.parse
     非 {items: array} → markFailed E_LLM
8. 每条 item：丢掉未知字段；若含 path / [[ / 完整 frontmatter → 该条 E_VALIDATION
   type 不在三值、title/body 不合法 → 该条错误，不写
   写前去重（§3.4）→ duplicate
   linkify
9. 写 extracted.json：{ items: [{ …ExtractedItem, status:"pending"|"written", path? }] }
10. dryRun? 返回 kept 无 path
11. queue.execute 一次：pending 项 captureWrite
    撞 path（同 title 同模板）→ 文件名追加 -2、-3（不是整场失败）
    某条抛错 → 仍 return 已写 paths
12. 全写成 markDone；否则 markFailed + kept_paths
```

LLM / 去重 / complete **不持** `write.lock`。flush 消息：`compile session <id>`。  
同 id 并发：第二场等锁或 `E_LOCK`。  
空 `items[]`：`markDone`，dropped 含 `empty`（不是 failed）。  
job 结束后 **不** `layers.auto`。

`complete` 参数（P6.1）：temperature 0，max_tokens 4096，timeout 60s；不强制 `json_object`。

### 3.3 Prompt

权威文本：`packages/core/resources/session-extract-v1.md`（禁止输出 path/wikilink/frontmatter；空数组合法；剥离已注入记忆；few-shot 决策/教训/噪声）。

实现时读该文件组 `system`；user 侧只放 turns（`role: text` 行）。

> **P6.6**：system 改为三类型合同；user 增加 Session Time、可选 Already-in-kb、可选 `source_turns`。组包与验收见 [`P6.6-extract-contract.md`](P6.6-extract-contract.md)。P63-11 仍有效。

### 3.4 写前去重

```yaml
compile:
  dedupe_cosine: 0.95
  dedupe_window: 200
  max_input_chars: 32000
  tool_max_chars: 2000
```

embedding on：cosine ≥ 阈值 → duplicate。  
off：余弦跳过 + `skipped_reason=embedding_off`；**仍做** title+body 规范化全等。

### 3.5 linkify

`entity.list()` slug+aliases；`stripCodeBlocks`；最长匹配；已是 `@slug` 不包；别名 ≥2 字；英文 `\b` 边界。

### 3.6 模块

| 模块 | 路径 |
|---|---|
| 编译器 | `packages/core/src/compile/session.ts` |
| 解析 turns | `packages/core/src/compile/parse.ts` |
| 挂链 | `packages/core/src/compile/linkify.ts` |
| 写盘节点 | `captureWrite` in `write/capture.ts` |
| prompt | `packages/core/resources/session-extract-v1.md` |

无 `heuristic.ts` 产品路径。

### 3.7 `captureWrite`

从 `captureNode` 抽出「校验 + 写一颗 md」。`captureNode` = `execute(() => captureWrite)` + `maybeAutoAbstract`（M2 不变）。会话路径只调 `captureWrite`。

## 4. 返回形状

```ts
type CompileResult = {
  session_id?: string;
  kept: Array<{ type: string; title: string; path?: string; links?: Array<{ to: string }> }>;
  dropped: Array<{ reason: "duplicate" | "noise" | "empty"; excerpt: string }>;
  unresolved: string[];
  errors: Array<{ message: string; code?: string }>;
  skipped_reason?: string;
  truncated?: boolean;
};
```

## 5. 验收

| ID | 功能点 | Given / When / Then |
|---|---|---|
| P63-01 | mock 决策 | mock `complete` 返回一条 decision → kept≥1 且有 md |
| P63-02 | 噪声 | mock 返回 `{items:[]}` → kept=[]；markDone |
| P63-03 | 余弦去重 | local embedding；先 capture 同类；再 compile 近似 → duplicate |
| P63-03b | 全等去重 | embedding off；两句规范化相同 remember → 第二条 duplicate |
| P63-04 | 挂链 | entity alice；body 提 Alice → `@alice` |
| P63-05 | unresolved | 未登记专有名 → unresolved 非空 |
| P63-06 | 无 API | `provider=off` → `E_DISABLED`；无新 md；无 extracted.json |
| P63-07 | 不冒充启发式 | off 时即使正文含「我们决定」也不写 L0 |
| P63-08 | 一次 execute | 两候选 → `execute` 恰好 1 次、`captureWrite` 两次 |
| P63-09 | 剥离注入 | turns 仅含 context 块内「我们决定」→ mock 收到的 prompt **不含**该句 |
