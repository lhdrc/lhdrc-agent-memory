# Spec P2.2 — 蒸馏（L1）与 L0/L1 分层

| 字段 | 值 |
|---|---|
| ID | P2.2 |
| 状态 | done |
| 依赖 | M3, P2.1a（向量预筛可关则改 BM25 预筛） |
| 对应架构 | 08 §6.0、§6.4、§6.5、D3、D17 |

## 1. 目标

1. 异步蒸馏：从 source 节点生成 `brains/{id}/experiences/*.md`  
2. OpenViking 两级判定词表按 D17 **重映射**（delete ≠ 删源）  
3. `memory_diff` 审计文件，可回滚经验层  
4. L0 abstract / L1 overview 生成（可 LLM；kill-switch 关则用截断启发式）  
5. CLI：`memory refine`；查询可滤 experience  
6. **索引 experiences**（覆盖 M3「跳过非 sources」）；写入走 **WRITE_FORMAT / validateWrite（D14）**  

## 2. 非目标

- 结晶 SKILL、dream、observer/cost（**P3.2**）  
- 修改/删除 `sources/**` 下源文件  
- MCP / REST（**P4.1**）  

## 3. LLMProvider（本 Spec 最小）

```ts
interface LLMProvider {
  judgeDistill(existing: string[], candidate: string): Promise<DistillDecision>;
  generateAbstract(content: string): Promise<string>;
  generateOverview(children: string[]): Promise<string>;
  refineExperience(ctx: ExperienceContext): Promise<ExperienceResult>;
  embed?(texts: string[]): Promise<number[][]>; // 可复用 P2.1a
}

type DistillDecision = {
  candidate: "skip" | "create" | "none";
  item?: "merge" | "delete";   // delete → superseded
  targetExpId?: string;
  confidence: number;
  rationale: string;
};
```

`memory.yml`：

```yaml
llm:
  provider: off | openai | ...
  distill: true
  kill_switch:
    distill: false
    abstract: false
```

`provider=off` 或 kill_switch：蒸馏跳过（CLI 明确提示）；abstract 用前 100 字启发式。

## 4. 经验文件格式与 WRITE_FORMAT

`brains/{brainId}/experiences/{ulid}.md`：

```markdown
---
title: ...
schema_type: experience
status: active            # active | superseded | archived
trigger: "..."
procedure: |
  ...
boundary: "..."
source_paths: ["sources/.../decisions/1-....md"]
version: 1
created_at: ...
supersedes: []            # exp ids
superseded_by: null
# P3.2 预留（本 Spec 写入默认值即可，不实现 outcome 回调）
eta_score: 0.5
support: 0
counter_examples: []
---
## 摘要
## 正文
```

**D14**：扩展 [`../mvp/WRITE_FORMAT.md`](../mvp/WRITE_FORMAT.md)（或同目录 `WRITE_FORMAT-experience.md` 并由 `validateWrite` 分发）——经验层 create/merge/supersede **必须**经校验后进 WriteQueue；禁止旁路写盘。

## 5. 索引规则（相对 M3 的修订）

M3 约定：MVP 跳过非 `sources/` 下 md。**本 Spec 起**：

| 路径前缀 | 索引 |
|---|---|
| `brains/{id}/sources/**` | 继续索引（L0） |
| `brains/{id}/experiences/**/*.md` | **必须**进 `pages`/`chunks`；`schema_type=experience` 可滤 |
| `brains/{id}/skills/**` | 仍可跳过直至 **P3.2** |

`rebuild-index` 与写后 hook 均遵守上表。验收：`query --type experience` 能命中刚 refine 出的文件。

## 6. 蒸馏管线（严格）

```
refine(sourceId | path):
  1. 读取候选源节点（只读 sources）
  2. 拼 candidate 文本（title+facts+body 截断）
  3. 预筛相似 experiences（embedding cosine 或 BM25）top 5
  4. LLM judgeDistill → decision
  5. 映射执行：
     - skip/none → 不写；记 diff noop
     - create → 新建 experience md（validateWrite）
     - item merge → patch 已有 experience（merge_op=append 字段级）
     - item delete → 旧经验 status=superseded；源 md 字节不变（断言）
  6. 全部经 WriteQueue（文件权威 + 索引 hook）；按 D18 dirty/flush（不要求每条 distill 单独 git commit）
  7. append memory_diff
```

**测试断言（致命）**：蒸馏前后 `sources/` 下源 md **字节不变**（可用文件 hash / 内容比对；若已 flush，亦可用 `git diff -- sources/` 为空作辅助断言）。

## 7. memory_diff

路径：`brains/{id}/events/{YYYY-MM}/memory_diff.jsonl`

```json
{
  "id": "diff_...",
  "at": "ISO",
  "op": "experience_create|experience_merge|experience_supersede|abstract_update",
  "paths_written": ["experiences/..."],
  "paths_readonly_refs": ["sources/..."],
  "decision": { },
  "revert": { "action": "archive_path", "path": "experiences/..." }
}
```

CLI：`memory changes [--limit]`；`memory revert <diffId>`（仅支持经验层归档回滚，不做任意 git revert 封装）。

## 8. 分层

- 节点 frontmatter 增：`abstract`（L0）、`overview`（L1）  
- **选定 frontmatter 字段**，避免 `.{name}.abstract.md` 文件爆炸  
- 目录级 overview：二期可只做文件级，目录聚合可 stub  

检索默认返回 abstract/overview；`memory read --layer l2` 全文。

## 9. CLI

```
memory refine [--source <id>] [--path <node>]
memory query "..." --type experience
memory changes
memory revert <diffId>
```
