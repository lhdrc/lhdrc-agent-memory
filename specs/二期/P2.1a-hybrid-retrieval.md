# Spec P2.1a — 混合检索（向量 + BM25 + RRF）

| 字段 | 值 |
|---|---|
| ID | P2.1a |
| 状态 | ready |
| 依赖 | M3 |
| 对应架构 | 08 §5.6、§7.1–7.2、§14 search mode |

## 1. 目标

1. Embedding 可插拔：本地默认 / 云端 / **关闭**  
2. `chunks.embedding` 写入与 stale 重算  
3. 语义召回 + BM25（含中文 ngram）→ **RRF(k=60)** 融合  
4. `search mode`：conservative | balanced | tokenmax（tokenmax 的扩写/rerank 可先 stub）  
5. 中文检索硬门禁测试集  
6. CLI：`memory query` 升级；新增配置项  

## 2. 非目标

- 图谱臂、graph signals、意图调权、search_cache（**P3.1**）  
- cross-encoder 必须实现可用；不可用时 tokenmax 降级为 balanced  
- MCP / REST（**P4.1**）  

## 3. EmbeddingProvider

```ts
interface EmbeddingProvider {
  readonly id: string;
  readonly dims: number;
  embed(texts: string[]): Promise<number[][]>;
}

// 实现
class OnnxLocalEmbedding implements EmbeddingProvider  // 默认；模型路径可配
class OpenAIEmbedding implements EmbeddingProvider
class NoopEmbedding implements EmbeddingProvider       // embed() 抛 E_DISABLED；检索跳过语义臂
```

`memory.yml`：

```yaml
embedding:
  provider: local | openai | off
  model: bge-small-zh-v1.5   # 示例
  openai_api_key_env: OPENAI_API_KEY
```

切换 provider 或 dims 变化 → 强制 `rebuild-index --embeddings`。

## 4. 向量存储

- PGLite：用 `REAL[]` 或 `BYTEA`（float32 LE）；MVP 已有 BYTEA 则延续  
- 相似：应用侧 cosine；先用 brute-force `ORDER BY` 在 SQL 外算（节点 <5k 可接受）  
- 节点规模声明：二期单机目标 ≤5000 pages；超出提示换 PostgresEngine（可只留接口）  

## 5. 召回与融合（本 Spec 冻结；无图臂）

**权威公式以本 Spec 为准**（覆盖 08 §7.2 在「无 graph 臂」时的裁剪形态；含 graph 的完整权重见 **P3.1**）。

### 5.1 臂内 RRF

```
A = bm25Arm(q, limit*3)          # 复用 M3
B = semanticArm(q, limit*3)      # provider=off 则空
for each arm: assign rank 1..n
rrf_arm[path] = Σ 1/(k + rank_i) # k=60；同 path 在臂内 max-pool
```

### 5.2 臂间加权（balanced 默认）

```
final = 0.45 * rrf(bm25) + 0.45 * rrf(semantic) + 0.10 * title_path_boost_norm
```

- `title_path_boost_norm`：标题/路径命中的归一化 boost ∈ [0,1]  
- conservative：仅 `bm25 + title/path`（等价加强版 M3；语义臂权重视为 0）  
- semantic 不可用时自动按 conservative，不报错  
- 最终按 `final` 排序，同 path 再 max-pool，取 top N  

> 禁止再实现「只做 Σ 1/(k+rank) 跨臂累加却不加权」的第二套 balanced；测试夹具以本节为准。

## 6. search mode CLI

```
memory query "..." --mode conservative|balanced|tokenmax
```

或 `memory.yml`：`search.mode: balanced`。

tokenmax（本 Spec 最小）：

- 可选：简单同义词表扩写 0–1 条（零 LLM）  
- LLM 扩写 / rerank：接口预留，kill-switch 默认关  

## 7. 中文门禁（必须进 CI）

手挑 ≥12 条 query fixture：`packages/core/tests/fixtures/zh_queries.json`

```json
[
  {
    "id": "zh01",
    "setup": ["capture title 支付网关超时 body ..."],
    "query": "网关超时",
    "expect_path_substr": "支付",
    "top_k": 5
  }
]
```

门禁：`top_k` 内命中率 ≥ 10/12，否则 fail CI。
